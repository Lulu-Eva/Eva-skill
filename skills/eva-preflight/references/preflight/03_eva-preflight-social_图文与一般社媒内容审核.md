# Eva Preflight 03：图文与一般社媒内容审核

本文件适用于小红书图文、朋友圈、微博和其他一般社媒成稿。Preflight 可以审核这些内容，但不得借此扩大 Eva Create 的生产边界。

## 1. 薄语义承诺检查

只问四件事：

1. 标题或首句让读者期待看到什么？
2. 正文是否真正回答了这个期待？
3. 读者能否说清这条内容的核心信息、判断或行动？
4. 是否存在关键事实、第一人称经历或商业承诺无法确认？

小红书图文有标题时检查标题与正文；朋友圈、微博或无标题内容检查首句与后文。这里不继承短视频标题搜索、前三秒、第一句话交接卡和正文路线图闸门。

## 2. 只读调用

默认只读调用：

- `../eva-shared/references/quality/00_eva-ai-check_表达真实性审查.md`
- 本文件的薄语义承诺检查

商单内容追加 Commerce 03 和商单约束真源；用户/团队自有稿按 `04_eva-preflight-expression-assets_表达资产增强.md` 检查表达资产。

普通审核再按 00 公共层静默轻扫标题/首句与后文是否仍对同一类人说话、回答同一个真实问题，不为此默认加载 Audience 00 或 01。用户明确要求完整检查“最后在替谁说话、是否写偏人群或写后人群对位”时，才按 05 只读调用 `../eva-shared/references/audience/01_eva-audience-alignment_写后人群对位.md`。

## 3. 判断边界

- 不用短视频“前 5 秒”标准审判朋友圈或微博。
- 不要求每条社媒都有完整论证、故事弧光、小标题或 CTA。
- 标题/首句承诺正文没有回答、核心意思无法辨认、关键事实被写成确定结论时，可以形成发布级阻塞。
- 轻微人群或用户问题漂移只算优化建议，不降低“可以发布”。只有漂移已经造成标题/首句承诺断裂、核心意思无法辨认，或正文实质回答了另一群人的问题时，才归入前述既有根因。
- 句子略长、画面感可增强、转场可优化等通常只是软建议。
- 不要求一般社媒内容具备强情绪、强冲突、明确敌人或转发动机；温和、真诚、信息型或个人化表达不能仅因“不够有共鸣感”被判错。
- 需要完整重写时，只指出适合基础模型、用户指定 Link 或相应专业能力；Preflight 不接管生产。
