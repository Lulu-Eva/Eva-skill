# Eva Lens 学科发散

学科发散用于一个话题、现象或疑问已经出现，但用户还没有形成稳定观点时，用最有解释力的学科打开新变量。它的核心是**筛选和转译**，不是堆砌学科名词。

## 进入条件

命中任一情况时可以使用：

- 用户明确说“从几个学科发散”“用社会学、心理学、经济学等视角看”“帮我找更多解释机制”。
- 用户以泛化的“用 Lens 看看”进入 Eva Lens，只提供了话题、现象或问题，还没有可反驳的明确判断。用户明确说“多元视角 / 四个视角”时走快速补光，不进入本流程。
- Eva Think 已经承接上下文，用户在当前对话里明确要求跨学科打开话题。

只有“帮我想想”“陪我聊聊”“帮我发散选题”，但没有学科、机制或理论视角意图时，不自动使用本流程；这仍属于 Think 的轻量陪聊和灵感发散。

## 先压缩待解释问题

把用户输入压缩成一句真正需要解释的问题，例如：

```text
不是：女生要去大城市。
而是：哪些结构、激励和身份机制，会让大城市对某些女性的职业与生活选择更有利？这个判断的边界又是什么？
```

不要在压缩时替用户预设结论。输入过于空泛、连待解释对象都无法确定时，最多问一个会改变学科选择的问题。

## 候选学科池

以六个基础学科作为稳定起点，但不封闭在六类里：

| 基础学科 | 主要解释对象 |
|---|---|
| 哲学 | 价值判断、概念边界、伦理困境与选择代价 |
| 社会学 | 群体、阶层、结构、规范、城市与关系网络 |
| 经济学 | 激励、资源配置、机会成本、市场与博弈 |
| 商业 | 产品、组织、竞争、职业路径与商业模式 |
| 心理学 | 认知、动机、情绪、身份与行为偏差 |
| 科学 | 自然规律、系统机制、技术条件与可验证原理 |

话题需要时，可动态扩展到人类学与文化研究、历史、传播学、制度与公共政策、教育学、语言学、法学或其他更有直接解释力的领域。候选池只用于后台筛选，不把它整份展示给用户。

## 领域筛选

对候选领域后台判断四件事：

| 标准 | 判断问题 |
|---|---|
| 直接解释力 | 能否解释现象为什么发生，而不只是换一套术语？ |
| 互补程度 | 是否提供前两个领域没有的新变量？ |
| 内容转译价值 | 能否形成用户听得懂、愿意继续追问的内容角度？ |
| 可验证性 | 后续是否有事实、经历、案例或证据路径可寻找？ |

默认选择：

```text
2 个核心解释领域
+ 1 个差异领域
```

前两个负责解释主机制；第三个必须带来新变量、新边界或反向压力。如果第三个只能重复前两个，直接缩减为两个，并说明当前没有第三个同等强度的学科；不为了格式凑数。

用户只点名一个学科时，只处理该学科。用户给出多个学科作为建议时，仍按解释力筛选，可用更匹配的领域替换弱项并说明原因；用户明确说“只看这几个”时，不超出指定范围。

## 每个学科的处理

对每个入选学科，只回答四件事：

1. 它为什么适合这个问题。
2. 它看见的核心机制是什么。
3. 这个机制可以转成什么内容角度或追问。
4. 后续需要用什么经历、案例、数据或来源验证。

理论名称只能用来帮助说明机制，不能代替推理。对名称或归属不确定时，将其写成“可进一步核验的理论线索”，不写成已验证证据。

## 证据与出口边界

- 不自动联网，不编造论文、研究、数据、名言、精确引用、案例或平台事实。
- 不写“研究表明”却不给可核验来源。用户需要真实论据、数据或引用时，有可用搜索能力就同轮搜索并核验；当前无法搜索时只给“要核验的问题 + 证据类型”。只有用户明确要系统学习、主题研究或建立学习项目时才交 Eva Learn，不因一次证据检索擅自建档。
- 不自动识别话题人群；用户进入人群判断时，交给 Audience Finder。
- 不写完整稿、不改完整稿。用户选定方向并明确要创作后，再交给 Eva Create。
- 不替代四视角快速补光或深度审视。深度审视可以选两个学科做压力测试，但不读取或输出本流程的完整三学科报告。
- 谁调用，控制权就返回给谁。Lens 调用后留在 Lens；Think 调用后回 Think 承接用户选中的方向，不为了显示顶层入口再跳 Lens。
