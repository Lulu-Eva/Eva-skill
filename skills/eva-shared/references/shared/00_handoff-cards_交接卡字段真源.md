# Eva-skill 交接卡字段真源

本文件是标题交接卡、第一句话交接卡和正文路线图最低字段的唯一字段真源。

商单约束卡、商单内容任务卡和二者转换规则的唯一真源是 `../eva-shared/references/shared/03_commercial-constraint-card_商单约束卡真源.md`。

使用方式：

- 生成、校验或补齐标题交接卡、第一句话交接卡和正文路线图最低字段时读取本文件。
- 子模块只保留本模块的进入条件和退回规则，不重复整张字段表。
- 缺硬字段时退回对应上游；不得由下游猜字段。

## 标题交接卡

输出标题交接卡时，标题承诺、验证线索和内容兑现必须成立；或 Eva 已完成一次标题搜索提醒，用户第二次明确接受先出未验证草稿。

```markdown
## 交给 /eva-script 的内容任务

- 标题谜面：
- 标题来源：一字不改使用 / 结构迁移 / 已验证候选标题 / 低置信度试结构
- 标题验证状态：已验证 / 未验证-用户授权试结构
- 人群状态：已由 audience-finder 校准 / 标题模块临时假设 / 用户直接给出 / 不清楚
- 讲给谁：
- 具体处境：
- 真实缺口：
- 主谜面：
- 正文标题作用：共同谜面 / 点击增强 / 补充情绪 / 补充结果 / 不进入正文主线
- 用户最想知道：
- 必须先回答：
- 本稿不回答：
- 建议写法：观点类 / 干货类 / 观点开路 + 干货收束
- 点赞点：
- 收藏点：
- 表达资格点：
- 可用素材：
- 可回捞素材：普通点子卡 / 人设素材卡 / 暂无
- 可搜索共鸣词：
- 成稿置信度上限：高 / 中 / 低
```

低置信度标题交接卡必须同时满足：

- 标题来源写“低置信度试结构”。
- 标题验证状态写“未验证-用户授权试结构”。
- 成稿置信度上限只能写“低”。
- 缺素材、经历、数据或评论区原话的位置必须写占位符。

人群状态必须如实标注：

- 只有本轮执行过 `../eva-shared/references/audience/00_eva-audience-finder_话题人群识别器.md`，才写“已由 audience-finder 校准”。
- 标题模块临时判断，只写“标题模块临时假设”。
- 用户只给出对象但未拆具体处境和真实缺口，写“用户直接给出”。
- 判断不出来，写“不清楚”。

## 第一句话交接卡

无标题完整视频稿链路不补标题交接卡，先形成第一句话交接卡。

```markdown
- 第一句话：
- 停留理由：
- 人群状态：已由 audience-finder 校准 / 第一句话临时假设 / 用户直接给出 / 不清楚
- 讲给谁：
- 具体处境：
- 真实缺口：
- 主谜面：
- 用户继续看最想知道：
- 必须先回答：
- 本稿不回答：
- 建议展开方式：完整内容 / 先补主体素材
- 可用素材：
```

第一句至少要让人确认话题入口；停留理由与兑现线索可以由必要的一至三句整体完成。一句已成立时不补句；整体仍不成立时，不进入完整正文，停在开头分支继续补。

## 商单内容任务卡字段说明

商单内容任务卡只作为商单正文链路的约束字段，不是标题交接卡、第一句话交接卡或正文路线图最低字段。

输出、校验或转换商单内容任务卡时，读取 `../eva-shared/references/shared/03_commercial-constraint-card_商单约束卡真源.md`，不得在本文件里维护第二套商单字段。

## 普通正文简版路线最低字段

标题交接卡或第一句话交接卡已经成立后，普通、非商单、单一主问题、素材足够的正文可以使用简版路线：

```markdown
- 路线类型：普通简版
- 人群状态：
- 讲给谁：
- 具体处境：
- 真实缺口：
- 主谜面：
- 标题来源：
- 标题验证状态：
- 成稿置信度上限：
- 用户最想知道：
- 核心判断：
- 可用真实素材：
- 展开路线：在本字段内记录“用户原有理解 → 最少必要节拍链 → 本稿允许抵达的新理解”及必要期待覆盖；不新增节拍字段或固定拍数
- 本稿不回答：
- 不得编造：
- persona-card 状态：
- voice-card 状态：
```

简版路线不能用于：商单、标题/主问题冲突、长素材尚未选定入口、故事承担主结构但变化不清、论证和一手细节同时不足、用户要求深度审视或完整发布审查。

## 复杂正文完整路线最低字段

复杂正文、商单和异常分支必须承接已经过完整正文路线图模块的结构卡。最低字段如下：

```markdown
- 人群状态：
- 讲给谁：
- 具体处境：
- 真实缺口：
- 主谜面：
- 标题来源：一字不改使用 / 结构迁移 / 已验证候选标题 / 低置信度试结构 / 不适用
- 标题验证状态：已验证 / 未验证-用户授权试结构 / 不适用
- 成稿置信度上限：高 / 中 / 低 / 不适用
- 本稿只回答：
- 本稿不回答：
- 建议写法：
- 展开关系：
- 递进路线：在本字段内记录全稿起点、最少必要节拍链与本稿允许抵达的新理解
- 必须写进正文：
- 不要展开：
- persona-card 状态：
- voice-card 状态：
- 成稿置信度：
- 主问题拆层：清楚 / 不清楚
- 用户期待清单：1..N 条必要期待；数量只服从主承诺和理解需要
- 期待-正文层映射：保留兼容字段名；动态记录一项期待由一拍或多拍回答、多项相邻期待由同一拍回应，以及本稿明确舍弃的期待；不得机械一一对应正文层级
- 用户期待清单状态：清楚 / 不清楚
- 叙事弧光：适用-成立 / 适用-不成立 / 不适用
- 外部共鸣证据状态：已提供 / 可补 / 未提供-不使用
- 可引用的外部共鸣证据：允许为空
- 不得伪造的外部证据：
```

商单内容还必须带入 `../eva-shared/references/shared/03_commercial-constraint-card_商单约束卡真源.md` 规定的商单约束字段。缺 Brief 禁区、必提、不可承诺内容或学员可用素材时，退回正文逻辑链推理，不得直接写稿。
