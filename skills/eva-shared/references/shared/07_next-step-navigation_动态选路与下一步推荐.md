# Eva-skill 动态选路与下一步推荐

本文件是 Eva 2.x 的跨模块导航真源。它只负责根据当前目标、最近结果和真实阻塞决定“现在先去哪一站”，不替任何业务模块完成任务。

## 1. 何时读取

只有命中以下任一情况时读取：

- 用户问“下一步怎么走、先用哪个功能、你建议从哪里开始”。
- 用户明确要求入口排序、候选入口或完整工作流。
- 原始请求已经包含两个以上阶段，需要判断是否同轮接力。
- 当前模块已经形成有效结论，需要判断返回调用者、继续原始目标，还是推荐后停止。

入口明确、当前模块仍在正常执行、普通聊天还没有阶段结论时，不为显示导航而额外读取本文件。

## 2. 导航优先级

始终按以下顺序判断：

```text
用户明确目标
> 原始请求中尚未完成的目标
> 当前硬闸门或返回原调用者
> 最新任务结论
> Eva Think 默认兜底
```

规则：

- 用户明确点名入口、最终产物或下一动作时，覆盖系统推荐，但不能绕过 Brief、标题验证、真实素材、安全、许可或保存确认等硬边界。
- 不根据预设固定链路决定下一步。最近一次有效产物、阻塞和用户新反馈才是导航依据。
- 不把“可能有帮助”当成“必须进入”。Learn、Lens、Audience、Preflight 和 Review 都只在意图或条件成立时出现。
- 当前信息不足时，优先给现有证据允许的阶段判断；只有两个方向会产生明显不同的交付且无法判断时，才问一个问题。

## 3. 任务前选路

### 路径清楚

直接读取目标入口并同轮执行，不展示候选菜单，不要求用户确认已经说清楚的任务。

### 轻微歧义但可以合理判断

用一句任务语言说明默认判断，然后同轮执行。例如：

```text
你现在还在形成判断，我先陪你把这件事聊清楚；如果后面要从学科机制打开，再切到 Eva Lens。
```

入口名只能放在任务结果之后，不能让用户先理解内部架构。

### 结果方向无法区分

只问一个能改变交付的问题，默认最多两个结果导向选项。例如：

```text
你是想把这份资料真正学懂，还是直接把它写成一篇文章？
```

只有用户明确要求对 Eva 做“入口排序、排个 123、给候选入口”时，才最多展示三个入口；推荐项放第一位，并说明一句依据。不得借此展示完整功能表。

内容产物数量不是入口数量；只有用户明确要求对 Eva 的入口、功能或路线排序时，才进入入口排序。

### 默认兜底

用户只想聊聊、目标仍模糊或只是说“帮我看看”时，默认由 Eva Think 轻量接住。出现“话题、资料、稿子”等名词本身，不足以自动进入 Audience、Learn、Create 或 Preflight。

## 4. 任务后接力

先判断当前任务是否已经完成，再选择以下一种处理；前台每次只出现一个下一步。

### 同轮继续

仅在以下情况继续：

- 原始请求已经明确授权下一阶段，例如“聊清楚后写成文章”“拆完 Brief 后做短视频”“审核并改好”。
- 当前调用属于 Create 等模块的必要内部闸门，完成后必须回到原调用模块。
- 用户明确说“按你的推荐继续”。

同轮继续时，用一句话说明刚才形成了什么、现在为什么接下一步，然后直接读取目标入口。不要让用户重新输入命令。

### 推荐后等待

以下情况完成当前任务后停止，只推荐一个方向：

- 下一步会扩大用户原始请求的范围。
- Think 已聊清楚，但用户没有说要创作。
- Lens 已完成发散或压力测试，但用户没有要求继续写或改。
- Learn 已完成当前学习，但用户没有要求转成内容。
- Create 已交付成稿，下一步是 Preflight。
- Preflight 已给出结论，下一步需要用户修改、发布或补材料。
- Review 已形成测试动作，下一步是制作新内容。

推荐不是隐性授权。用户确认、补充材料或明确新目标后再继续。

### 必须停止

需要用户亲自搜索标题、补 Brief、补真实经历、确认保存、正式发布、等待观察窗口或回填数据时，停止执行并说明唯一解除动作。不得用另一个模块假装完成现实世界动作。

## 5. 工作流展示

只有用户明确要求“给我一个工作流、帮我安排步骤、从头到尾怎么走”时才展示工作流。

根据当前目标和已完成状态，从以下六类阶段中选择必要部分：

```text
当前判断
→ 必要前置
→ 内容生产
→ 发布前审核
→ 用户现实动作
→ 发布后复盘
```

展示规则：

- 每一步标记“必需”或“按需”，并标出当前所在阶段。
- 不为了显得完整而强行加入 Learn、Lens、Audience、Preflight 或 Review。
- 用户只要求查看流程时，展示后等待；用户同时要求“按这个开始”时，只执行第一个未完成阶段。
- 后续方向仍根据实际结果重新判断，不承诺固定长链一定成立。
- 用户明确要求入口排序时可附入口名；普通工作流优先使用“聊清判断、识别人群、写成稿、发布前审核”等任务语言。

## 6. 模块接力地图

| 当前模块或结果 | 默认终点 | 允许接力的条件 |
|---|---|---|
| Think | 阶段性判断、核心冲突或一个验证动作 | 原始目标明确包含创作时进入 Create；明确要求学科发散或压力测试时进入 Lens |
| Audience Finder | 具体人群、认知缺口、用户问题 | 独立分析后停止；同时要求创作时进入 Create；内部调用返回原模块 |
| Lens | 发散方向、最大盲区、薄弱前提或否证条件 | 独立调用后停止；原始目标包含继续写或改时返回 Think/Create |
| Learn | 当前讲次、理解状态或继续学习动作 | 不自动转内容；明确要求“学完做内容”时，判断未形成先 Think，判断和形式都清楚再 Create |
| Brief | Brief 拆解、商单约束或缺失材料 | 独立拆解后停止；原始目标包含商单内容生产且约束齐全时进入 Create |
| Create | 搜索方案、标题/第一句话、文章或短视频成稿 | 内部闸门继续；成稿默认只推荐 Preflight；提前要求“写完顺便审”才同轮进入 Preflight |
| Preflight | 三档发布判断和一个最高优先级动作 | 只审核则停止；“审核并改好”才交正确修改能力；通过后先由用户发布 |
| Review | 一个可证伪假设和下一轮测试动作 | 只有明确要求制作下一篇时才进入 Create、Link 或对应写作能力 |
| Memory | 保存结果、1—3 张回捞卡或盘点结果 | 任务回捞返回调用者；保存和盘点完成后停止 |
| Link | 当前 Link 执行、Builder 或 Doctor 结果 | 只完成用户明确的 Link 任务，不因导航机制自动扩展工作流 |
| New User | 一个最小练习或用户真实任务 | 用户开始正式任务时同轮进入对应入口；不要求先学完教程 |

组合意图继续遵守以下既有边界：

- AI Check 只检测时停在检测；明确局部改一处时局部处理；完整重写按最终内容形式进入 Create 或基础写作能力。
- 局部内容创作或发散留在对应 Create 分支；完整待发稿的发布前总检进入 Preflight，Preflight 只审核、不继承生产动作。
- 有用户样本且目标是以后照着写时进入 User Voice；只查假空机械时进入 AI Check。
- 长文档按最终动词判断：带学进入 Learn，写作进入 Create，样本拆解进入 Benchmark，保存个人材料进入 Memory。
- 商单只拆 Brief 或对照约束时留在 Brief；商单内容生产必须先有合格约束，再进入 Create；正式品牌赞助文章继续遵守当前版本边界。
- Review 先形成一个待验证变量；用户明确制作下一篇时再进入生产能力。用户要求从多元视角补复盘结论的盲区时可转 Lens，但 Lens 只审视当前结论，不重新做数据归因。
- Preflight 只审核时停止；“审核并改好”先完成审核，再只修改最高优先级问题。
- 商单整篇发布前综合总检由 Preflight 给三档结论；缺 Brief 时把唯一下一步交给 Brief，不绕过审核结论。
- 获客短视频不新增入口：目标或真实产品未清、或只规划内容矩阵时进 Think；单条信息齐全且要成稿时进 Create；待发总检进 Preflight；发布后有真实反馈时进 Review。
- 本文件只决定当前站；信任判断、可信依据、CTA、四重一致性和发布后求证由各模块按需读取 shared 08，不在这里复制，也不自动连续执行完整获客链。

## 7. 循环与越权边界

- 内部调用遵守“谁调用，控制权返回给谁”，不为了显示一级入口回根路由重判。
- Audience 不在 Audience、Think、Create 之间循环；Lens 返回原入口后不再次自动调用 Lens；Brief 与 Preflight 之间没有新材料时不得来回跳转。
- 用户没有提供新信息、确认或材料时，不重复推荐同一个下一步。
- 尚未发布的内容不得进入 Review；已经发布的表现数据不得回到 Preflight 解释结果。
- 普通创作不得自动建 Learn 项目；普通成稿不得自动做 Preflight；Preflight 不自动改稿；Review 不自动制作下一篇。
- 动态导航不得绕过既有 Audience、标题/第一句话、Brief、低置信度、外部材料安全和保存确认规则。
- 不保存用户的默认工作流偏好，不新增导航资产、状态字段、schema 或 handoff target。
