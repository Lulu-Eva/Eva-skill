# 表达资产轻量预加载协议

本文件是 Eva 2.0.5 的表达资产轻量预加载真源。它只解决一件事：用户已经保存过 `persona-card` 或 `voice-card` 时，Eva 的高频入口能在不进入完整 Memory 流程的情况下，用这些资产保护表达资格和用户文风。

## 定位

轻量预加载不是完整回捞，不是保存，不是建档。

硬边界：

- 只读。
- 不保存。
- 不生成新卡。
- 不推断。
- 不编造。

它只做只读预检：

```text
当前运行项目 ./eva-memory/persona/
当前运行项目 ./eva-memory/voice/
-> 找到和当前任务最相关的 1-3 张表达资产
-> 标注命中状态
-> 只使用卡片里的真实字段
```

不得扫描 Eva Skill 仓库本体，不得跨项目扫描，不得扫描用户没有指定或没有权限的目录。

## 入口适用范围

| 入口 | 默认策略 |
|---|---|
| `eva-think` | 首轮默认不预检；只有人设资格、用户文风、已保存经历或转短视频确需个性化时应用，不读取 Harness / Asset 协议 |
| `eva-create` | 不因进入 Create 自动预检；只有个性化标题、开头、路线图或成稿确需人设、真实经历或文风时应用 |
| `eva-link` | Link 输出接回 Eva 时应用；防止外部模块输出变成通用腔 |
| `eva-learn` | 学习本身不预加载；只有学习结果要转内容、观点、思想种子或交接创作时应用 |
| `eva-brief` | 不默认预加载；只有检查已有商单稿、或交回 Create 成稿时，才可作为表达资产状态参考 |

## 触发时机

允许触发：

- 用户当前任务涉及“我为什么能讲”“像我自己说”“按我的语气写”“不要 AI 腔 / 璐璐腔”。
- Create 即将进入标题兑现、正文逻辑链、正文路线图或正文撰写。
- Link 输出要交给 Eva Memory / Create。
- Learn 的学习结果要转成内容、观点、思想种子或创作素材。
- Brief 要检查已有商单稿是否符合用户人设和文风，或要把约束交回 Create。

禁止触发：

- 用户只是普通学习、带读、资料理解。
- 用户只是普通聊天，且当前话题不需要个人表达资格或长期文风。
- 用户只是拆 Brief 的产品、卖点、禁区和必提信息。
- 当前运行项目没有 `eva-memory/`，或没有 `persona/`、`voice/` 子目录。

未触发或未命中时，不向用户报告“未命中”，不追问，不把轻量预检变成阻塞条件。

## 扫描范围

只允许扫描：

```text
./eva-memory/persona/
./eva-memory/voice/
```

匹配依据：

- 文件名。
- frontmatter。
- keywords。
- 摘要。
- 卡片中已经存在的真实字段。

禁止：

- 根据用户当前输入反向编造 persona-card 或 voice-card。
- 把普通聊天内容临时当成已保存资产。
- 扫描 `skills/eva-shared/`、`skills/eva/` 或其他 Skill 仓库目录。
- 因预加载自动保存新卡；预加载不保存任何资产。

## 命中数量

默认最多返回 1-3 张表达资产：

- persona-card：最多 1-2 张。
- voice-card：最多 1 张。

如果命中过多，只取和当前任务最相关的资产，不展示资产仓库列表。

## 使用规则

命中 `persona-card` 时，只能使用卡片里已有的：

- 表达资格。
- 身份来源。
- 真实经历。
- 选择代价。
- 隐私边界。
- 不适合使用的素材。

具体个人经历、失败、收入、关系、身份、创伤、家庭、健康和他人信息属于高分量素材。使用前必须判断卡片里的隐私边界：

- 已标注可公开，且和当前任务强相关：可以使用，但必须使用“具体素材提示”。
- 标注为后台、私密、不适合公开或边界不清：不得直接写入正文；只可作为内部理解，或当轮向用户确认。
- 用户当轮明确授权使用：可以使用授权范围内的素材，但不得扩大到卡片里其他私密字段。

命中 `voice-card` 时，只能使用卡片里已有的：

- 核心文风。
- 句子节奏。
- 词汇舒适区。
- 读者关系。
- 避免规则。
- 典型表达。

不得把 persona-card 当账号定位包装，不得把 voice-card 当固定口头禅库。

## 当前指令与 voice-card 优先级

当轮用户新指令优先于已加载 `voice-card`，但只影响本轮输出，不自动改写长期资产。

处理规则：

- 用户说“语气再冲一点 / 更克制 / 更口语 / 更像我刚才那版”时，按当轮指令调整，但仍守住 `voice-card` 的真实表达边界。
- 如果当轮指令只是风格强度变化，优先在句式、密度、锋利程度和节奏上调整，不编造新的口头禅或人格。
- 如果当轮指令要求伪造经历、突破隐私边界、写成明显不像用户的腔调，必须拒绝或降级。
- 如果用户说“更新我的语气卡 / 保存这个新风格 / 以后都按这个来”，才转入 Memory 保存流程；预加载本身不得覆盖 `voice-card`。

## 前台提示

只有命中且实际应用时，首轮提示一句。按实际使用分两类：

只使用文风、节奏、读者关系或表达边界时，用轻提示：

```text
我会顺手用你之前保存的人设/文风资产，但这轮不展开资产字段。
```

使用具体个人经历、失败、收入、关系等保存素材时，用具体素材提示：

```text
这版会用到你之前保存过的个人经历素材；我只用和这次内容相关的部分，不展开完整资产。
```

如果具体素材涉及敏感或边界不清，先问一句授权，不直接写入正文：

```text
这里会用到你之前保存过的一段个人经历，但它有隐私边界。我先不直接写进去，除非你确认这次可以公开使用。
```

如果没有命中、没有目录、没有权限或未扫描，不提示，不追问。

用户要求查看命中的资产时，再转入 Memory 或 Asset 相关真源；默认不展示完整字段。

## 状态归一

预加载结果必须归入 `01_asset-state_资产状态归一表.md` 的状态，不新增状态体系。预加载与后续 Create 主动回捞检查点的复用、重新扫描和覆盖优先级，只读取 `01_asset-state_资产状态归一表.md` 的“预加载与主动回捞优先级”；本文件不维护第二套状态解释。

允许写入内部状态：

```text
persona-card 状态：主动回捞-已命中 / 主动回捞-未命中 / 未扫描-无目录 / 未扫描-无权限 / 未扫描-未执行
voice-card 状态：主动回捞-已命中 / 主动回捞-未命中 / 未扫描-无目录 / 未扫描-无权限 / 未扫描-未执行
```

前台默认不展示这些状态。

## 失败边界

- 没有 `eva-memory/`：按未扫描处理，不报错。
- 没有 `persona/` 或 `voice/`：按未扫描处理，不报错。
- 文件无法读取：按未扫描-无权限处理，不报错。
- 卡片字段不完整：只使用可确认字段，其余按未提供处理。
- 卡片与当前任务不相关：视为未命中。

轻量预加载失败不得阻塞 Think、Learn、Brief 初拆或普通低个性化 Create。
