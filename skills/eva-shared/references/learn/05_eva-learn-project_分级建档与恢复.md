# Eva Learn 分级建档与恢复

本文件是 Eva Learn 项目建档、分级扩展和恢复的唯一真源。所有明确进入 Eva Learn 的任务都必须先建立或恢复可追溯档案；新项目先创建单文件项目锚点，第一讲产生真实内容后再扩展档案。

## 硬闸门

```text
触发 Learn
-> 确定项目位置
-> 新项目创建 00-学习进度.md 项目锚点 / 恢复现有档案
-> 验证项目锚点可写
-> 同轮进入教学
-> 第一讲内容形成后创建问答原稿和必要资料索引
```

- 未成功建档或恢复前，不得输出第一讲、学习目录、阅读任务、掌握判断或思想种子卡。
- 项目锚点、资料保存、进度更新或问答原稿追加失败时立即停止，不得说“已经记录”。
- 建档路径和文件清单默认不向用户展示；只有失败、路径冲突或用户要求查看时才说明。

## 项目位置

按顺序选择：

1. 用户指定目录。
2. 当前运行项目的 `./eva-learn/`。
3. `~/Documents/eva-learn/`。

如果当前目录是 Eva Skill 源码、安装后的 skills 目录或插件缓存，不得在其中创建学习项目，改用用户指定目录或 `~/Documents/eva-learn/`。

主题名规则：

- 有明确主题时使用主题名。
- 有资料时使用资料名、书名或中心问题的短名称。
- 只有模糊词时可以使用临时主题名，并在进度文件记录后续修正。
- 连临时名称都无法确定时，只问：“这次学习项目先用什么主题名保存？”

## 第一讲前的项目锚点

所有新学习项目在第一讲前只必须创建：

```text
eva-learn/{主题名}/
└── 00-学习进度.md
```

初始最低内容：

```yaml
建档状态: 初始化
建档等级: 最小 / 完整待展开
主题:
资料状态: 无资料 / 单份资料 / 多份资料 / 待确认
当前讲次: 未开始
下一步动作: 第一讲
```

项目锚点写入成功后，同一轮立即开始第一讲。不要先创建空的问答原稿、资料索引或完整档案文件。

第一讲内容形成后、展示给用户前：

1. 创建 `07-学习问答原稿.md`，写入第一讲和本轮交互。
2. 更新 `00-学习进度.md`，把 `建档状态` 改为“进行中”。
3. 有资料时才创建 `sources/INDEX.md` 和 `sources/原始资料/`；无资料时不创建空目录。
4. 如果属于完整档案条件，再创建当前实际需要的完整档案文件；不为尚未产生的内容创建空文件。

这样不允许“先聊几轮再补档”。项目身份在第一讲前已经建立，实际内容在产生时写入。

## 建档等级

### 最小档案

适用于：

- “带我学懂”一个概念或问题。
- “带我读”一份或少量资料，且没有长期研究、多资料对读或继续项目要求。

第一讲前只创建上面的项目锚点。第一讲形成后至少扩展为：

```text
eva-learn/{主题名}/
├── 00-学习进度.md
├── 07-学习问答原稿.md
└── sources/（仅有资料时）
    ├── INDEX.md
    └── 原始资料/
```

最小档案不是临时会话。项目锚点在第一讲前创建；第一讲及之后每一轮都必须更新进度并追加问答原稿，以保证完整追溯。

### 完整档案

命中任一条件时把项目锚点标记为“完整待展开”，并在第一讲形成后按实际内容创建完整结构：

- 用户明确说系统学习、完整学一遍、长期研究。
- 用户要求主题式阅读、多资料对读或比较研究。
- 用户要求继续上次项目或恢复已有进度。
- 当前最小项目升级为多资料、长期或跨阶段项目。

完整结构上限：

```text
eva-learn/{主题名}/
├── 00-学习进度.md
├── 01-探究问题卡.md
├── 02-阅读谱系.md
├── 03-阅读任务记录.md
├── 04-理解检查记录.md
├── 05-判断版本.md
├── 06-思想种子卡.md
├── 07-学习问答原稿.md
└── sources/
    ├── INDEX.md
    └── 原始资料/
```

## 最小档案的按需扩展

以下文件在首次产生对应内容时创建，创建失败则停止该阶段：

| 首次产生的内容 | 创建文件 |
|---|---|
| 明确探究问题 | `01-探究问题卡.md` |
| 默认知识谱系或阅读路径 | `02-阅读谱系.md` |
| 第一讲任务、资料范围或讲次索引 | `03-阅读任务记录.md` |
| 第一次理解检查 | `04-理解检查记录.md` |
| 可验证判断版本 | `05-判断版本.md` |
| 成熟思想种子 | `06-思想种子卡.md` |

按需创建不允许跳过对应模块的内容闸门，只避免在项目开始时生成无内容空文件。

## 进度最低字段

`00-学习进度.md` 至少维护：

```yaml
建档状态: 初始化 / 进行中 / 恢复中 / 写入失败
建档等级: 最小 / 完整
当前旅程: 01 / 02 / 03 / 04 / 待判断
当前 Phase: 待判断 / 对应旅程实际 Phase
当前讲次: 第 n 讲 / 未开始
资料状态: 无资料 / 单份资料 / 多份资料 / 待确认
学习目标尺度: 待确认 / 学科型 / 应用型 / 制度型 / 内容素材型
掌握状态: 未开始 / 完全掌握 / 基本掌握 / 部分理解 / 尚未理解 / 假性流畅 / 未验证
下一步动作: 只写一个动作
理解债: []
```

## 每轮追溯

教学开始后，每轮必须：

1. 把本轮讲解、用户回答、Eva 反馈和掌握判断追加到 `07-学习问答原稿.md`。
2. 更新 `00-学习进度.md` 的讲次、Phase、掌握状态、下一步动作和理解债。
3. 有资料时更新 `sources/INDEX.md`，并保证原始资料已保存或登记。
4. 对应阶段产生新记录时，创建或追加相应文件。

任何一步写入失败，本轮不得声称已经保存，也不得继续生成需要该记录作为前提的下游资产。

## 从最小升级为完整

升级时：

- 保留已有进度、问答原稿、资料索引和原始资料。
- 创建尚不存在的完整结构文件，不覆盖已有内容。
- 把 `建档等级` 更新为 `完整`，记录升级原因。
- 继承当前旅程、讲次、掌握状态和理解债，不重置项目。

## 恢复项目

恢复时先读取 `00-学习进度.md`，再读取当前旅程需要的文件：

- 未读取进度前，不得声称知道上次讲次。
- 当前目录没有项目时，只问项目路径；找到多个候选时让用户选择。
- 缺进度文件、字段异常或记录冲突时停止恢复，按需读取 Harness/Asset 说明失败项。
- 恢复最小档案时允许继续按需扩展；恢复长期、系统或多资料项目时先升级为完整档案。

## 前台口径

建档成功后不展示文件操作，只自然进入教学：

```text
有资料：资料已收到。我先判断它真正要解决什么，然后直接带你读第一步。
无资料：我先给你一条默认学习路径，再从第一步开始讲。
```

只有失败、路径需要用户决定或用户要求查看状态时，才说明项目位置和文件状态。
