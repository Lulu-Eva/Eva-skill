# Eva Learn 04：思想种子卡与内容链路交接

适用场景：Eva Learn 已产生阶段性判断，用户想沉淀，或想把学习结果转入短视频/文章内容链路。

本文件只做思想种子卡和交接判断，不直接写稿。

先按用户的最终动词选形式：

```text
做成短视频 -> 执行本文件下方的人群、标题/第一句话与正文路线交接
写成非虚构自媒体文章 -> 带上阶段性判断、证据、反对证据和不确定处，交给 Eva Create Article
```

以下“标题 / 第一句话 / 正文路线图”闸门只属于短视频。Article 按自己的读者任务、材料分层和论证闭环执行，不要求先有标题或第一句话交接卡。

## Article 交接优先

- 用户最终要写 Article、没有明确要求“保存 / 沉淀”时，不强制生成思想种子卡。直接携带阶段性判断、支持证据、反对证据和不确定处，同轮交给 Eva Create Article。
- 用户同时明确要求“沉淀后写成文章”时，先按下方规则生成并写入思想种子卡；写入成功后，同轮把同一组判断与材料交给 Eva Create Article。
- 未验证内容只能作为不确定材料交接，必须保留未验证状态，不得升级为事实。

完成任一 Article 交接后，停止执行本文件下方的短视频成熟度、标题 / 第一句话和正文路线图流程。

## 思想种子卡生成条件

满足任一条件才进入思想种子卡生成前检查：

- 用户能复述、举例、反驳和迁移。
- 用户形成清楚的阶段性判断。
- 用户明确说要沉淀。
- 一个学习小闭环已经完成。

以下情况不得生成：

- 本轮掌握状态是“未验证”。
- 用户只是看完资料，但没有自己的判断。
- 只有书摘、摘要、概念表，没有判断版本。
- 最终目标是短视频，且用户想跳过人群、标题或第一句话直接成稿。

用户说“帮我沉淀”不等于可以生成思想种子卡，只表示可以进入生成前检查。生成前必须先过检查表。

## 生成前检查表

生成思想种子卡前，逐项检查：

- 是否已有判断版本。
- 是否已有掌握状态。
- 掌握状态是否不是“未验证”。
- 是否有支持证据。
- 是否有反对证据或不确定处。
- 是否能写出“可讲给谁”。
- 是否能保存到 `06-思想种子卡.md`。

任一项不满足，不生成思想种子卡，只说明缺口，并路由回 `01 探索式学习`、`02 资料带学` 或 `03 主题式阅读` 继续学习。

如果掌握状态是“基本掌握”或“部分理解”，但判断、证据、不确定处都已经清楚，可以生成“低置信度思想种子卡草稿”，只用于后续学习回收，不得作为已验证资产交给内容链路。用户仍明确要写 Article 时，只能把原始材料作为不确定材料交接，不得把草稿卡升级为事实。

## 思想种子卡格式

```text
## 思想种子卡：{标题}

- 来源项目：
- 触发问题：
- 阶段性判断：
- 支持证据：
- 反对证据：
- 我的经验/场景：
- 可讲给谁：
- 用户可能正在问：
- 不确定处：
- 成熟度：萌芽 / 可进入内容入口 / 可进入正文前校验
- 下一步：
```

思想种子卡必须保留“不确定处”。不要把阶段性判断包装成绝对真理。

生成前确认 `06-思想种子卡.md` 已存在；最小档案没有该文件时按 `05_eva-learn-project_分级建档与恢复.md` 先创建。生成后追加到 `06-思想种子卡.md`，关键问答追加到 `07-学习问答原稿.md`。创建或写入失败时停止，不得继续资产生成或创作交接。

## 短视频成熟度判断

| 成熟度 | 标准 | 下一步 |
|---|---|---|
| 萌芽 | 有兴趣或概念，但判断、证据、用户场景不清 | 回到 `01 探索式学习`、`02 资料带学` 或 `03 主题式阅读` 继续学习 |
| 可进入内容入口 | 有判断和材料，但人群、用户疑问、标题或第一句话不清 | 交给 `../eva-shared/references/audience/00_eva-audience-finder_话题人群识别器.md` 或 `../eva-create/references/create/shortvideo/title/00_eva-title_标题即选题.md` |
| 可进入正文前校验 | 判断、证据、人群、用户疑问和入口都清楚 | 仍需先过标题/第一句话交接，再进入正文链路 |

禁止使用“可成稿”作为成熟度。

## 短视频内容链路硬闸门

思想种子卡不是：

- 标题交接卡。
- 第一句话交接卡。
- 正文任务卡。
- 商单约束卡。

进入内容链路必须经过：

```text
思想种子卡 -> 人群/用户疑问判断 -> 标题或第一句话入口 -> 正文路线图 -> 正文撰写
```

## 短视频内容入口预备卡

思想种子卡进入内容链路前，必须先输出内容入口预备卡。它不是标题交接卡、第一句话交接卡或正文任务卡，只负责把学习成果交给人群、标题或第一句话入口。

```markdown
## 内容入口预备卡

- 阶段性判断：
- 支持证据：
- 反对证据 / 不确定处：
- 可讲给谁：清楚 / 不清楚
- 用户可能正在问：
- 真实缺口：
- 适合平台：小红书 / 抖音 / 视频号 / 待确认
- 建议入口：先做人群判断 / 标题搜索 / 第一句话开头
- 不得直接写成稿的原因：
```

缺 `可讲给谁`、`用户可能正在问` 或 `真实缺口` 任一项时，必须先读取 `../eva-shared/references/audience/00_eva-audience-finder_话题人群识别器.md`。

路由规则：

| 当前缺口 | 读取 |
|---|---|
| 不知道讲给谁 | `../eva-shared/references/audience/00_eva-audience-finder_话题人群识别器.md` |
| 要做小红书、有标题、需要封面标题 | `../eva-create/references/create/shortvideo/title/00_eva-title_标题即选题.md` |
| 做抖音/视频号、无标题口播、前 5 秒 | `../eva-create/references/create/shortvideo/script/00_eva-script_思维流爆款内容创作.md`，再按需读 `../eva-create/references/create/shortvideo/opening/00_eva-opening_开头针对性优化.md` |
| 标题交接卡或第一句话交接卡已经成立 | `../eva-create/references/create/shortvideo/script/00_eva-script_思维流爆款内容创作.md` |

## 短视频交接前状态闸门

| 节点 | 未完成前禁止 | 唯一下一步 |
|---|---|---|
| 未生成思想种子卡 | 禁止进入内容链路 | 先执行生成前检查表 |
| 未判断成熟度 | 禁止路由到标题或正文 | 先判断萌芽 / 可进入内容入口 / 可进入正文前校验 |
| 成熟度为萌芽 | 禁止进入内容链路 | 回到 `01 探索式学习`、`02 资料带学` 或 `03 主题式阅读` 继续学习 |
| 未输出内容入口预备卡 | 禁止路由到标题、第一句话或正文 | 先输出内容入口预备卡 |
| 缺少人群或用户疑问 | 禁止进入标题和正文 | 读取 `../eva-shared/references/audience/00_eva-audience-finder_话题人群识别器.md` |

## 短视频交接禁止

- 不把思想种子卡直接改成完整稿。
- 不绕过人群、标题或第一句话入口。
- 不把未验证学习结果包装成确定观点。
- 不编造用户经历、书中案例、引文或页码。
