# Eva Learn 03：主题式阅读

适用场景：用户提供多份资料，或围绕一个主题想比较多个作者、流派、案例和观点。

本文件是一条线性旅程：

```text
多资料存档 -> 共同问题 -> 谱系定位 -> 交叉路径 -> 逐讲对读 -> 掌握检查 -> 产出表 -> 完成判断
```

进入本文件前必须已经完成完整建档。若未建档，或仍是最小档案，返回 `05_eva-learn-project_分级建档与恢复.md` 完成创建或升级；任何创建、资料保存或写入失败都立即停止。

## Phase 1：多资料存档

先登记资料，不直接比较。

必须执行：

1. 每份资料编号：`S1`、`S2`、`S3`。
2. 保存或登记到 `sources/原始资料/`。
3. 更新 `sources/INDEX.md`：资料名、作者/来源、类型、核心主题、可读性状态、用途。
4. 标记资料状态：核心资料 / 补充资料 / 反对资料 / 案例资料 / 待判断。
5. 将每份可读资料切成可回查片段，编号为 `S1§1`、`S1§2`、`S2§1`。片段可以按自然段、标题段、页码或语义块划分。

资料不可读时，不使用该资料做结论。

## Phase 2：确认共同问题

主题式阅读的核心不是“读很多资料”，而是让多份资料共同回答一个问题。

按顺序判断：

| 输入状态 | 动作 |
|---|---|
| 用户已有明确问题 | 复述并写入 `01-探究问题卡.md` |
| 用户只有主题 | Eva 默认代选一个最能贯穿多份资料的共同问题，写入 `01-探究问题卡.md`，并标注置信度 |
| 资料之间没有共同问题 | 说明无法主题式阅读，建议改为 `02 资料带学` 分别带学 |

一次只使用一个共同问题。

只有多个共同问题会导致完全不同对读路径时，才给 2-3 个候选让用户选。否则不得默认停下让用户判断共同问题。

共同问题不可判定或资料之间没有共同问题时必须停下。共同问题已由用户提出或 Eva 默认代选时，可以继续进入资料谱系定位、交叉学习目录和逐讲对读。

## Phase 3：资料谱系定位

为每份资料标注位置：

- 核心命题：这份资料主张什么。
- 证据来源：它靠什么证明。
- 反对对象：它在反对谁或修正谁。
- 使用边界：它解释不了什么。

核心命题、证据来源、反对对象和使用边界都必须带资料片段编号。没有片段编号的内容只能标为 Eva 推断或待核实。

不确定作者、版本、立场、背景时标注“待核实”。

资料关系低置信度时，只能标为“待判断”。不得编造正反关系、流派关系、时代关系或作者争议。

## Phase 4：交叉学习路径

根据资料关系选择一种路径：

| 资料关系 | 路径 |
|---|---|
| 主资料 + 反对资料 | 正反命题对读 |
| 理论资料 + 案例资料 | 理论到场景迁移 |
| 同主题不同时代 | 概念演变 |
| 同主题不同作者 | 分歧焦点 |
| 多份资料没有稳定关系 | 先回到共同问题，缩小范围 |

输出交叉学习目录，默认 3-5 讲；大型主题 6-9 讲。

## Phase 5：逐讲对读

每讲必须先在后台生成对读掌握目标卡，但前台不得输出“对读掌握目标卡”这个标题。前台只说清本讲要比较什么、分歧在哪里、用户听完要能区分什么。

后台对读掌握目标卡必须包含：

- 本讲比较哪两份或哪几份资料。
- 本讲资料片段编号，如 `S1§1-S1§3`、`S2§2`。
- 本讲共同问题的哪一部分。
- 本讲分歧点是什么。
- 用户要能区分什么。
- 掌握检查题。
- 通过标准。

“用户要能区分什么”只能从以下三类里选：

- 能区分不同资料的核心命题。
- 能区分命题和证据。
- 能区分作者立场和自己的判断。

每讲必须区分四类内容：

```text
作者命题：作者在主张什么
证据来源：作者靠什么支撑
反对意见：谁不同意，为什么
争议焦点：真正分歧在哪里
```

作者命题、证据来源、反对意见和争议焦点必须带资料片段编号。没有片段编号的内容只能标为 Eva 推断或待核实。

每讲只比较一个分歧点，不同时比较所有资料。

每讲结尾只给一个轻量掌握反馈问题：

```text
你现在更同意哪边？依据是什么？能不能用自己的经验举一个例子？
```

## Phase 6：掌握检查

掌握状态：

| 状态 | 判定标准 | 下一步 |
|---|---|---|
| 完全掌握 | 能区分各方命题、证据、分歧和自己的判断 | 即时沉淀后进入下一讲 |
| 基本掌握 | 能说出主要分歧，有少量混淆 | 纠偏，记录理解债，进入下一讲 |
| 部分理解 | 只复述观点，分不清证据和立场 | 回到资料对照表补一小段，记录理解债，默认继续 |
| 尚未理解 | 不知道各方在争什么 | 判断影响后续；低/中影响缩小到两份资料后继续，高影响先补讲 |
| 假性流畅 | 只说态度，没有资料依据 | 要求补证据定位 |
| 未验证 | 用户跳过检查 | 可浏览式推进，但不得生成判断版本或思想种子卡 |

未完成即时沉淀前，不得标记本讲已掌握；但可以标记为“已浏览 / 待回收”，继续下一讲。理解债的创建、回收和关闭必须遵守 `00_eva-learn.md` 的生命周期规则。

## Phase 7：主题式产出

每讲结束必须先做即时沉淀，追加到 `07-学习问答原稿.md`：

- 共同问题。
- 本讲资料范围。
- 本讲资料片段编号。
- 各方命题。
- 用户判断。
- Eva 纠偏。
- 掌握状态。
- 理解债。

阶段完成后，输出并保存四张表：

- 概念表：不同资料如何定义关键概念。
- 命题表：各作者/资料的核心主张。
- 证据表：每个主张的证据来源。
- 争议表：真正分歧点。

四张表中每一条作者命题、证据和争议判断都必须包含资料片段编号；没有片段编号只能标为 Eva 推断或待核实。

四张表分别追加到 `03-阅读任务记录.md` 或用户指定文件；关键问答仍追加到 `07-学习问答原稿.md`。

## 最小状态闸门

| 节点 | 未完成前禁止 | 唯一下一步 |
|---|---|---|
| 多资料未存档 | 禁止比较、禁止目录 | 登记资料并更新 `sources/INDEX.md` |
| 可读资料未切片 | 禁止作者命题、证据表和争议表 | 切成 `S1§1` 这类可回查片段 |
| 共同问题不可判定 | 禁止谱系定位、禁止对读 | 说明卡点，缩小资料范围或改为分别带学 |
| 资料关系待判断 | 禁止编造关系 | 缩小到两份资料或标注待核实 |
| 关键误解未处理 | 禁止进入下一讲 | 先补一个关键误区 |
| 未完成即时沉淀 | 禁止标记已掌握 | 写入共同问题、资料范围、片段编号、命题、用户判断、掌握状态和理解债生命周期 |

## Phase 8：完成判断

阶段完成后，先检查当前掌握状态、资料片段编号和理解债。只有当前掌握状态不是“未验证”，核心命题和证据都有片段编号，且没有高影响 `open` 理解债，才输出判断版本并追加到 `05-判断版本.md`。

如果当前掌握状态是“未验证”，核心命题或证据缺片段编号，或仍有高影响 `open` 理解债，不得输出判断版本；只保存已浏览记录，并用一个轻量问题回收最关键卡点或补齐资料依据。

```text
判断版本 v{n}
- 共同问题：
- 我现在站在哪个判断上：
- 支持证据：
- 反对证据：
- 仍不确定处：
```

判断版本保存失败时停止，不读取 `04_思想种子卡与内容链路交接.md`。未写入 `05-判断版本.md` 前，不得生成思想种子卡。

满足条件时读取 `04_思想种子卡与内容链路交接.md`：

- 用户能说清共同问题。
- 用户能区分至少两方命题和证据。
- 用户形成自己的阶段性判断。

## 禁止

- 不把多资料阅读做成资料摘要拼盘。
- 不在没有共同问题时硬做主题式阅读。
- 不把共同问题选择默认丢给用户。
- 不编造作者立场、争议关系、页码或引文。
- 不输出没有资料片段编号支撑的作者命题、证据或争议判断。
- 不把掌握检查变成默认考试。
- 不强迫用户每讲都达到完全掌握才继续。
- 不在即时沉淀前标记本讲已掌握。
- 不把阶段性判断直接写成完整内容稿。
