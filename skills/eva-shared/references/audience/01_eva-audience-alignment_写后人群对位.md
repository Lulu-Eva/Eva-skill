# Eva-skill 写后人群对位

本分支把话题人群识别器的核心判断延伸到成稿之后：

> 写前判断这个话题准备替谁说话；写后检查这篇内容最后真正让谁接住了。

它不是传播力预测、情绪强度测试或第二套发布审核。它只检查内容最终面对的人、回答的问题和原先想完成的表达是否仍然对位。

## 进入条件

只在以下任一情况成立时读取本文件：

- 用户提供标题、开头、片段或完整稿，并明确询问“写偏了吗”“最后在替谁说话”“这段有没有真正对人说话”“写完后检查人群对位”。
- 用户调用 `/eva-audience-finder` 并同时提供已经形成的稿件；默认按写后对位处理，不额外询问是写前还是写后。
- Eva Preflight 明确要求完整的人群对位结果；普通静默预检不因此加载本文件。

以下情况不进入：

- 只有话题、热词、现象或标题方向，且人群尚未建立：使用写前话题人群识别。
- 用户要求完整发布前审核：进入 Eva Preflight。
- 用户分析第三方内容结构、爆款原因或已发布表现：继续由 Benchmark、Think 或 Review 按各自边界处理。
- 用户只是要求改稿、续写或生成完整内容：按内容形式进入 Create，不把普通修改请求改成人群分析。

如果用户要求写后对位却没有提供可检查的文字，只问一次：

> 把想检查的标题、开头、片段或完整稿贴给我就可以。

## 判断依据

先读取写前真源 `00_eva-audience-finder_话题人群识别器.md`，沿用其中的具体人群、场域位置、认知缺口和用户问题。写后任务不执行其七步生产流程，不把反义场当作必要条件，也不继承公理 8 的内容入口与默认输出；本文件只改变观察方向和输出终点，不另建一套人群理论。

按以下顺序判断：

1. **实际接收者**：从标题、称呼、处境、概念难度、案例和行动要求中，判断当前文字实际更容易被哪种具体处境中的人接住；不得只写人口标签。
2. **可接住的内容**：判断对方能从中接住一段经历、一种感受、一项事实、一个有依据的判断或一套方法中的什么。
3. **原文依据**：指出支持判断的具体句子或位置。没有文本证据的受众心理不得补造。
4. **前后一致**：检查标题、开头与正文是否仍在面对同一类人、回答同一个真实问题。
5. **原定方向**：只有当前会话已经形成目标人群、认知缺口或用户问题时才比较；没有预设时，只描述稿件实际让谁接住，不反推账号定位。
6. **最大偏移**：只指出一个最影响理解或兑现的偏移；没有实质偏移时明确对位成立。

片段只能判断片段实际支持的范围，不推断未提供的正文。材料不足以确认实际接收者或用户问题时，返回“无法判断”，并只指出一个最小材料缺口。

## 临时状态

状态只用于本轮判断，不保存、不写入 Asset、schema 或 handoff：

- **对位成立**：实际接收者、用户问题和内容兑现一致；表达可以温和，也可以只是清楚地分享经历、事实、判断或方法。
- **轻微漂移**：局部概念、例子或语气暂时离开主要人群，但没有改变整篇回答对象和核心问题。
- **关键失焦**：标题、开头或正文已经面对不同人群、回答不同问题，导致原承诺断裂或核心内容难以被目标读者理解。
- **无法判断**：现有材料不足，且继续推断会变成猜测。

不得把“轻微漂移”写成不可发布，也不得因为表达不够激烈、没有冲突或没有情绪爆点而判为失焦。

## 不同内容如何成立

- **真诚经历**：处境真实具体，读者能够理解这段经历对自己意味着什么即可；不要求制造对立。
- **教程方法**：问题、动作和可观察结果清楚即可；不要求情绪故事。
- **信息解释**：让特定读者理解原本不清楚的事实或区别即可；不要求鲜明立场。
- **观点表达**：判断有依据、说话对象清楚即可；不要求树立敌人。
- **获客内容**：继续服从既有信任、产品事实和能力边界；人群对位不能自动增加产品、私信口令或 CTA。

## 默认输出

```markdown
## 写后人群对位

- 状态：对位成立 / 轻微漂移 / 关键失焦 / 无法判断
- 这篇实际让谁接住：
- 对方能从中接住什么：
- 原文依据：
- 与原定人群、认知缺口和用户问题：一致 / 局部偏移 / 关键失焦 / 无预设可比较 / 无法判断
- 当前一个最大偏移：没有则明确写“暂未发现实质偏移”
```

用户只要求复核时，交付后停止，不自动改稿。用户同时明确要求修改时，把一个最大偏移作为当前结论交还相应 Create 链路；不得在 Audience Finder 与 Create 之间循环。

## Preflight 只读调用

- 只有用户明确要求在发布前审核中完整检查人群对位时才启用；普通静默轻扫不得加载本文件。
- 取消本文件默认前台模板、改稿和 Create 接力，只按 Preflight 05 的统一字段返回状态、原文证据与一个最大偏移。
- 本分支只提供候选判断，最终发布准备度三档归 Preflight 00；不得自行降低等级或生成修改稿。

## 禁止事项

- 不把强烈情绪、冲突、反义场或推动行动设为成立条件。
- 不推测第一批传播者、转发动机、爆款概率、流量、完播或转化。
- 不套固定传播理论、理论标签或五维分析表。
- 不为了显得锋利而制造身份焦虑、愤怒、受害感或不存在的敌人。
- 不把缺少“共鸣感”单独写成发布阻塞。
- 不根据人群对位结果补造标题、案例、数据、产品承诺或 CTA。

## 最终原则

写后人群对位只有一个判断标准：

> 这篇内容是否把用户原本想分享的经历、事实、判断或方法，转译成了某种具体处境中的人能够接住的公共表达。

真诚、温和、清楚的分享本身可以成立；本分支不把所有内容改造成强观点内容。
