# Eva-skill 安装、版本与官方指南协议

## 唯一真源

- 面向用户的正式名称始终写作 Eva-skill。
- 当前版本、用户可感知更新、维护者和公众号文案以同目录的 release-notes.json 为唯一真源。
- 全局安装的十个可发现目录以同目录的 install-manifest.json 为唯一真源。

## 展示边界

只有受控安装器在完整校验、替换和 post-install 检查全部成功后，才能展示一次安装或升级卡。

- 新安装：Eva-skill 已安装完成 · v{version}。
- 受控旧版本升级：Eva-skill 已更新至 v{version}，再列出最多三条 release_highlights。
- 无受控旧状态的手工旧包、残缺包或修复：只能说安装或修复完成，不得伪称“已更新”。
- 同版本健康安装、安装失败、状态写入失败、降级和普通任务都不展示官方指南卡。

## 日常使用边界

以下场景绝不主动展示维护、公众号、案例库或版本卡：

- 裸 /eva 欢迎语；
- Think、Create、Learn、Brief、Link、Review、Lens 和 New User 的任何正常流程；
- 模块路由、任务收尾或普通对话；
- 无法写入安装状态的平台。

用户明确询问 Eva-skill 的当前版本、更新、安装、官方指南、案例或反馈时，eva 可以读取 release-notes.json 后回答。不得联网检查、自动安装、自动更新或写入用户状态。

## 隐私与状态

安装状态只能保存版本、安装时间、事务和提示确认状态；不得保存用户输入、内容素材、账号资料、行为记录或对话内容。

状态文件必须在 Skill 发现目录之外。安装器失败或状态不可写时，保留旧安装并压制一次性卡片，不能退化为在每次聊天中重复提示。
