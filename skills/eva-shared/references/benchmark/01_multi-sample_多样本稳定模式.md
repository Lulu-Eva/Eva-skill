# Eva-skill 多样本对标判断

只在当前任务有多个可比样本时读取。每个样本的基础判断仍以 `00_eva-benchmark-copy_对标文案拆解.md` 为真源。

## 比较门槛

- 一个样本：只能形成待验证判断，不宣称账号或类目规律。
- 两个样本：只比较异同、成立条件和不同的用户问题，不将重复写成稳定模式。
- 通常至少三个可比样本，才可以谨慎指出反复出现的模式。
- 样本平台、时间、账号阶段、内容形式或目标差异过大时，不强行合并。

## 输出判断

区分：

1. **反复机制**：在可比样本中重复出现，但仍是待验证假设。
2. **单篇偶然**：只在某一篇出现，或对当期热点、特定素材高度依赖。
3. **作者专属条件**：依赖作者身份、经历、账号积累或标志性表达，不对外迁移。
4. **当前无法判断**：样本不可比、数量不足或缺少必要证据。

重复出现不等于因果关系，多样本也不得被收束成固定爆款公式。

- 快速直出只提炼一个对当前任务最有用的比较判断，并保留待验证语气。
- 深度直出可展开反复机制、单篇偶然、作者专属条件和当前无法判断的部分，但不得把共现升级为因果。
- 深度带练每轮仍只推进一个比较判断，用户回答前不泄露完整比较结论。
