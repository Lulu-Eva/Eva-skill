# Eva 数据备份

本文件是 `/eva-memory` 的统一数据备份真源。只在用户明确要求导出、备份或打包 Eva 数据时读取；普通保存、任务回捞、记忆盘点、文件压缩和项目备份不得加载。

## 任务边界

Eva 数据备份只汇总已经正式落盘的数据：

- 当前运行项目的 `./eva-memory/`。
- 当前运行项目与 `~/Documents/eva-learn/` 中发现的 Eva Learn 项目。
- 用户本轮明确提供的其他 Eva Learn 项目路径。
- 当前运行项目中已经获得保存授权的 `./eva-review/`。

当前会话中仍然可见、已经形成结构但尚未保存的候选，不得直接夹带进压缩包。只有能整理成 `idea-card`、`persona-card` 或 `voice-card` 的候选，才可以先列出名称、类型、缺失字段和隐私状态；用户选中后，按 Asset 协议校验并正式保存，再进入备份。

不能找回或声称找回历史会话中没有落盘的内容。Learn 状态继续写回 Learn，Review 状态继续写回 Review；Harness 的运行状态、工具结果、失败记录和待确认标记不进入用户备份。

## 入口与普通文件任务隔离

只有下列带有明确 Eva 数据语境的表达才进入本模式：

```text
/eva-memory 导出 Eva 数据
备份全部 Eva 记忆卡
把我的 Eva 数据打包到桌面
导出 Memory，并把 Eva Learn 和 Eva Review 一起带上
```

“压缩这个文件夹”“备份这个项目”“把桌面资料打包”等普通文件任务不属于 Eva，不得抢占。

## 前台流程

### 第一步：只读预览

先读取 `../eva-shared/references/shared/06_external-material-safety_外部材料安全边界.md`，再优先调用：

```text
python3 <当前安装的 eva-shared>/scripts/eva_data_export.py preview \
  --project-root <当前运行项目> \
  --scope complete \
  --format json
```

预览不得写文件、创建目录或生成 ZIP。只向用户说明：

- 每个来源是否存在。
- Memory 卡片数与总体积。
- Learn 项目数、档案文件数、原始资料文件数与体积。
- Review 账号数、记录文件数与体积。
- 当前会话可见的未保存候选数量；没有可靠结构时写 0，不重新猜测。
- 符号链接、隐藏文件、临时文件、特殊文件等安全跳过项。
- 拟写入的目标目录。
- 完整包是本地未加密 ZIP，可能含个人经历、学习资料和账号数据。

预览只显示统计与安全范围，不展示正文、正文摘要或电脑绝对源路径。

### 第二步：一次选择范围

预览后只问一次：

```text
这次你想：

1. 只导出全部记忆卡；
2. 导出完整 Eva 数据包（记忆卡＋学习档案及原始资料＋账号复盘记录）；
3. 自定义导出范围。
```

三个选择的含义：

| 选择 | 范围 |
|---|---|
| 只导出全部记忆卡 | 仅当前项目 `./eva-memory/` |
| 完整 Eva 数据包 | Memory、全部已知 Learn 项目及其原始资料、当前项目已授权 Review 记录库 |
| 自定义 | 用户逐项选择 Memory、Learn、Review，并可排除 Learn 原始资料或补充其他 Learn 路径 |

不得把“盘点一下”当成导出授权，也不得把用户查看预览当成写入授权。

### 第三步：处理当前会话候选

如果预览时存在当前会话可见的未保存候选：

1. 合并列出，不连续追问。
2. 只把可长期复用的对象映射为 `idea-card`、`persona-card` 或 `voice-card`。
3. 用户选择后读取 Asset 协议与 `asset-types.json`。
4. 先形成 canonical Asset JSON；按照 Memory 真源的一次性 0600 临时文件与 `finally` 清理规则调用 `eva_memory_save.py`，完成确认、校验和正式保存。
5. `privacy_flags` 非空时，即使用户已授权批量保存，也要单独完成隐私确认。
6. 保存失败的候选不得进入压缩包，也不得说已经备份。

用户选择忽略候选时，直接按正式存档范围继续。历史会话未落盘内容始终写明“无法扫描”，不能把它包装成跳过项或恢复能力。

### 第四步：按最终范围重新预检，再明确执行

用户选定范围、额外 Learn 路径和原始资料选项后，并且当前会话候选已经保存或被忽略，必须使用这组**最终参数重新运行一次 `preview`**。第一次用于展示全貌的 `complete` 预览不能直接给 `memory` 或 `custom` 导出复用；任何候选保存都会改变文件集，也会让此前的 `plan_id` 失效。

最终预检只需说明相对第一次预览发生的范围、文件数和体积变化，并返回新的 `plan_id`。用户明确确认这份最终预检后，才允许使用完全相同的范围参数执行 `export`：

```text
python3 <当前安装的 eva-shared>/scripts/eva_data_export.py export \
  --project-root <当前运行项目> \
  --scope memory / complete / custom \
  --output-dir <用户确认的目录> \
  --confirm-export \
  --expected-plan-id <预览返回的 plan_id> \
  --format json
```

自定义模式按用户选择追加 Memory、Learn、Review、排除原始资料或额外 Learn 路径参数。不得用预览命令冒充实际导出，也不得在没有 `--confirm-export` 和匹配的 `--expected-plan-id` 时写文件。

`export` 的范围、Learn 路径、原始资料选项和目标目录必须与最终预检逐项一致；任一项变化都要再次预检，不能沿用旧 `plan_id`。

默认目标为可写的 `~/Desktop/`。桌面不存在或不可写时，只问目标目录，不静默改存 Documents、当前项目或 Skill 安装目录。

## 数据发现

### Memory

- 只读取当前真实项目根下的 `./eva-memory/`。
- 不读取其他项目、Skill 仓库、安装目录或全电脑 Memory。
- 备份正式存档；`INDEX.md` 可以作为派生索引保留，但不计作记忆卡。

### Eva Learn

按下列来源发现：

1. 当前项目的 `./eva-learn/`。
2. `~/Documents/eva-learn/` 下的全部有效学习项目。
3. 用户本轮明确提供的其他 Learn 项目路径。

有效学习项目必须以 `00-学习进度.md` 为项目锚点。额外路径只能指向单个有效项目，或直接包含有效项目的容器；不得递归扫描 Desktop、Documents、Home 或整台电脑。

同一项目从多个入口发现时，按真实路径去重，只打包一次。不使用目录修改时间判断项目身份、顺序或“最新版”。

完整模式包含 `sources/原始资料/`。预览必须单独展示原始资料的文件数和体积，并说明其中可能包含私人或受版权保护的原文件；自定义模式允许排除。

### Eva Review

- 只读取当前真实项目根下的 `./eva-review/`。
- 只纳入已经按 Eva Review 协议获得持续保存授权并正式落盘的设置、账号档案、记录、回填和规律报告。
- 不从其他项目搜集 Review，也不依据聊天内容临时生成 Review 记录。

## 安全过滤

所有来源统一遵守：

- 不跟随文件或目录符号链接。
- 不包含隐藏路径、临时文件、编辑器交换文件、缓存、日志、Git 数据、Skill 源码或已有 Eva 备份 ZIP。
- 只包含普通文件；FIFO、socket、设备文件和其他特殊文件必须跳过并记录原因。
- 归档相对路径不得为绝对路径，不得包含 `..`、反斜杠逃逸或重复 ZIP entry。
- 输出目录不得位于任一被扫描的数据根内部。
- 不联网、不上传、不删除、不移动、不重命名或改写源数据。

符号链接、隐藏文件、临时文件和特殊文件属于预先声明的安全跳过项。计划内普通文件不可读、复制失败或扫描不完整时，整次导出失败，不得生成“部分成功”的最终 ZIP。

## 压缩包合同

固定结构：

```text
Eva-data-backup-YYYYMMDD-HHMMSS/
├── README.md
├── MANIFEST.json
├── eva-memory/
├── eva-learn/
└── eva-review/
```

未选择或不存在的数据域不创建空目录。多个 Learn 来源可以在 `eva-learn/` 内使用不含绝对路径的稳定来源名称；同名项目不得互相覆盖。

`MANIFEST.json` 只记录：

- Eva-skill 版本。
- 导出时间与用户选择范围。
- 归档相对路径。
- 普通文件大小和 SHA-256。
- 总文件数、总体积与安全跳过原因。

不得记录电脑绝对路径、文件正文、正文摘要、对用户身份的推断或历史会话内容。

每个 ZIP 都是不可变时间点：

- 先在目标目录生成临时 ZIP。
- 完成 ZIP 文件数、CRC、逐文件 SHA-256 和 Manifest 一致性校验后，再原子改名。
- 同名时追加 `-02`、`-03`，永不覆盖旧备份。
- 验证失败只清理本轮临时 ZIP，源文件和既有备份保持不变。

## 完成输出

成功后只返回：

- 最终 ZIP 路径。
- 选择范围。
- 文件数和总体积。
- ZIP 的 SHA-256。
- 安全跳过项概览。
- “这是未加密本地备份，请自行妥善保管”的提醒。

不得输出文件正文、电脑绝对源路径或多步推广建议。用户没有要求其他动作时，完成后停止。

## 无脚本或权限不足

- Python 不可用时，可以按同一协议完成只读预览，但必须标注“当前为纯文本预览”。
- 无法可靠枚举全量文件时，只能报告已发现范围，不得称为完整备份。
- 没有文件写权限、目标目录不可用或无法完成完整性校验时，只返回预览和阻塞原因，不得声称 ZIP 已生成。
- 纯文本降级不允许跳过用户确认、隐私确认或源范围边界。

## 禁止

- 禁止因普通保存、回捞、盘点或文件压缩自动进入数据备份。
- 禁止把未确认候选、历史对话猜测或 Harness 运行状态直接塞进 ZIP。
- 禁止全盘扫描电脑寻找 Eva 数据。
- 禁止默认排除 Learn 原始资料后仍称为“完整 Eva 数据包”。
- 禁止生成空 ZIP、部分成功 ZIP、覆盖旧 ZIP或把失败写成成功。
- 禁止将本地未加密 ZIP 描述为加密、云备份或远程同步。
