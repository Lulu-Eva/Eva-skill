# Commerce 03：已有商单稿检查

只有稿件身份已明确为“学员自己的商单原稿”时，才进入本文件。如果用户同时提供 Brief 和一篇稿件但身份未说明，回 `../eva-shared/references/commerce/00_eva-commerce_商单主入口.md` 追问身份。

本文件只检查和交接，不完整成稿。

## 输入

- 品牌 Brief 或 Brief 解析结果。
- 学员自己的商单原稿。
- 可选：标题交接卡、第一句话交接卡、商单约束卡、表达资产。

如果用户动词是“检查、看看、能不能交、哪里不符合、帮我对照一下”，只进入本模式，不使用默认完整 Brief 拆解格式。

## 检查项

1. 是否漏掉 Brief 必提信息。
2. 是否写了 Brief 禁止信息。
3. 是否把可选卖点误写成主承诺。
4. 是否编造使用经历、数据或反馈。
5. 产品出现是否突兀。
6. 卖点是否只是在堆功能，没有场景。
7. 是否和学员人设、经历、点子卡或 `voice-card` 冲突。

## 接力规则

- 已有标题交接卡或第一句话交接卡，且商单约束卡满足 `../eva-shared/references/shared/03_commercial-constraint-card_商单约束卡真源.md` 的最低字段 -> 可接 `/eva-script`，先过正文逻辑链推理和正文路线图，再进入局部改稿。
- 只有标题文本、第一句话文本或普通原稿，没有标题交接卡/第一句话交接卡 -> 小红书/有标题链路先接 `/eva-title`，抖音/视频号/无标题链路先接开头分支，补齐内容入口。
- 如果商单约束卡缺最低字段 -> 回 `../eva-shared/references/commerce/01_brief-parse_Brief基础解析.md` 或 `../eva-shared/references/commerce/02_constraint-card_商单约束卡生成.md` 补齐，不接 `/eva-title` 或 `/eva-script`。

如果用户明确要求“直接改稿”，仍然不在本模块完整成稿，也不提供替换句、表达骨架或局部改写。只输出 Brief 风险、修改方向和商单原稿改稿交接卡；只有内容入口和商单约束都齐全时，才接 `/eva-script`。

## 禁止

- 禁止把检查写成完整改稿。
- 禁止在缺商单约束卡时直接判断“可以交”。
- 禁止因为原稿顺口就删掉品牌必提。
- 禁止用对标样本标准审判学员原稿。

## Preflight 只读调用

仅当 `eva-preflight` 已确认输入是用户本人或团队基本成形、尚未发布的商单稿时，本文件可作为商单约束只读判断真源：

- 只检查 Brief 必提、禁区、不可承诺内容、产品融入、卖点场景及使用经历/数据/效果/反馈的真实性；Brief 或约束卡不完整时返回“无法判断”及缺失材料，不得判定“可以交”。
- 取消 Brief 对照前台模板、商单改稿交接卡、稿件修改、约束卡生成、生产接力与下一步跳转，不保存。
- 按 Preflight 05 的统一协议返回候选判断，最终三档结论归 Preflight 00。
