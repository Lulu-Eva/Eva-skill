# Commerce 02：商单约束卡生成

本文件承接 Brief 解析结果，做表达资产匹配、主讲卖点筛选，并输出商单约束卡。字段真源仍然是 `../eva-shared/references/shared/03_commercial-constraint-card_商单约束卡真源.md`。

## 输入

- `../eva-shared/references/commerce/01_brief-parse_Brief基础解析.md` 输出的 Brief 解析。
- 卖点池。
- `persona-card`、经历卡、点子卡、`voice-card`。
- 用户明确授权的 `eva-memory/` 回捞结果。

## Phase 1：表达资产匹配

如果用户提供学员表达资产，按以下顺序匹配：

1. `persona-card`：这个卖点是否符合她为什么有资格讲。
2. 经历卡：她有没有真实经历能承接这个场景。
3. 点子卡：她有没有可复用观点、故事或案例能连接这个产品。
4. `voice-card`：这个卖点是否能用她自己的语气讲出来。

如果用户明确授权回捞表达资产，按 `../eva-shared/references/shared/01_asset-state_资产状态归一表.md` 的只读协议执行，并结合 `../eva-shared/references/memory/00_eva-memory_点子卡沉淀与回溯.md` 的回溯规则，按当前产品、目标用户、主讲卖点、账号方向和关键词检索运行项目的 `eva-memory/`。

回捞命中时，只使用命中的真实字段；回捞未命中、未扫描或无权限时，如实标注，不推断、不补全、不编造。回捞只服务本次 Brief 拆解，不自动保存新卡片。

以下状态值必须按 `../eva-shared/references/shared/01_asset-state_资产状态归一表.md` 归一，不得自造状态；经历卡、点子卡也按已命中类、未命中类、未扫描类或未提供类处理。

```markdown
## 学员表达资产状态

- persona-card 状态：
- 经历卡状态：
- 点子卡状态：
- voice-card 状态：

## 卖点匹配

| 卖点 | 匹配度 | 匹配原因 | 可用素材 | 缺口 |
|---|---|---|---|---|
|  | 高 / 中 / 低 |  |  |  |
```

匹配度判断：

- 高：卖点、学员经历、账号内容、人设资格和用户问题能自然扣上。
- 中：卖点和账号方向相关，但需要补真实使用感受或具体场景。
- 低：卖点和学员表达资产关系弱，讲出来容易像硬广或不像本人。

如果没有学员表达资产，也可以拆 Brief，但输出必须写：

```text
当前没有学员表达资产，所以卖点匹配只能按产品和通用用户场景低置信度判断。
```

## Phase 2：主讲卖点筛选

从卖点池里选 2-3 个最适合主讲的卖点。

优先级：

1. 品牌必提，且能自然场景化。
2. 和学员人设、经历或点子卡高度匹配。
3. 能解决用户真实问题。
4. 能用具体场景讲清楚。
5. 不需要编造使用经历。
6. 不容易夸大效果或引发合规风险。

输出：

```markdown

1. 卖点：
   - 为什么适合这个学员：
   - 可以接的真实素材：

   - 需要补充：

2. 卖点：
   - 为什么适合这个学员：
   - 可以接的真实素材：
   - 推荐表达角度：
   - 需要补充：

3. 卖点：
   - 为什么适合这个学员：
   - 可以接的真实素材：

```

不建议主讲，不等于不能出现。如果它是品牌必提但不适合作为主线，可以放到“轻轻带过”或“行动指令附近”。

## Phase 3：商单约束卡

本模块最终输出一张商单约束卡。它只提供品牌硬要求、卖点边界、真实素材缺口和合规风险，不承担标题、第一句话或正文结构功能。

输出字段、最低字段、素材缺失处理、推荐接力和商单内容任务卡转换规则，统一按 `../eva-shared/references/shared/03_commercial-constraint-card_商单约束卡真源.md` 执行。

本模块只做三件本地判断：

1. Brief 信息是否足够生成正式商单约束卡。
2. 主讲卖点是否适合当前学员表达资产。
3. 下一步应接 `/eva-title`，还是 `/eva-script` 的开头分支。

商单约束卡要先交给内容入口判断，不直接交给正文。缺正式商单约束卡最低字段时，停在本模块补 Brief；学员可用素材未命中、未扫描或未提供时，可以进入低置信度标题搜索或低置信度路线图，但不得进入高置信度正文成稿。

## 下一步

- 小红书、有标题或平台不清：接 `/eva-title`。
- 抖音、视频号、无标题口播或前 5 秒诉求：接 `/eva-script` 的开头分支。
- 已有标题交接卡或第一句话交接卡：商单约束卡可转换为商单内容任务卡，再进 `/eva-script`。
