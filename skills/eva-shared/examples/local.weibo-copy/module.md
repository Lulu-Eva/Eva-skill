# 微博文案

## 解决什么

把 Eva 已经沉淀的思想种子或判断版本，改造成适合微博发布的短文字。

## 不解决什么

- 不重新做人群判断。
- 不编造案例、数据、评论或个人经历。
- 不处理长文结构、商单 Brief、法律、医疗或财务专业判断。

## 输入要求

必须有：

- 核心判断
- 目标读者
- 发布平台

缺少时只问最短补齐问题，不直接编。

## 工作流程

1. 读取上游资产。
2. 检查核心判断、目标读者和发布平台是否完整。
3. 保留原始判断，不改写成立场相反的内容。
4. 改造成微博短文字，优先使用短句、清晰转折和一个明确结论。
5. 输出 `content-asset-card`。
6. 标注低置信度和不可交接部分。

## 模块内部输出格式

输出必须是 `content-asset-card`，字段以 Eva Asset 协议和 `schemas/asset-card.schema.json` 为准。不要在本模块维护第二套资产字段表。

## 禁止

- 不编造经历、数据、用户反馈或来源。
- 不绕过 Eva Asset。
- 不自动保存隐私资产。
- 不直接调用其他 Link。
