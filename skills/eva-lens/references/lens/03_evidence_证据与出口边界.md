# Eva Lens 证据与出口边界

Lens 默认检查证据结构，不负责检索真实证据。

## 证据检查

区分：

```text
用户提供的事实
基于输入的合理推断
尚未验证的假设
需要外部核验的事实
```

引用、论文、数据或案例只有在用户提供，或本轮确实调用搜索并核验后，才能写成来源。无法核验时改写为“需要寻找哪类证据”，不得生成貌似精确的出处。

## 出口

| Lens 结果 | 下一步 |
|---|---|
| 问题尚未形成清晰判断 | Eva Think |
| 需要真实资料、论据、数据或系统学习 | Eva Learn 或搜索能力 |
| 已明确短视频需要修改的位置 | Eva Create |
| 要检查发布后复盘结论是否偏窄 | 回 Eva Review |
| 要检查商单约束冲突 | Eva Brief |
| 用户明确要求保存结论 | Eva Memory，另行确认 |

Lens 自身不写文件、不生成资产、不改变长期偏好。跨模块交接只传递当前对话中的“最大盲区 + 一个动作”，不创建正式卡片。
