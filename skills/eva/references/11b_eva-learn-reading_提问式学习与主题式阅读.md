# Eva Learn 子模块：提问式学习与主题式阅读

本文件只处理学习前和阅读中的设计：

```text
问题澄清 -> 阅读谱系 -> 资料带读 -> 主题式阅读 -> 下一轮阅读任务
```

如果学习项目尚未建立，先返回 `11a_eva-learn-project_学习项目与资料存档.md`。Eva Learn 不允许在未建档状态下输出阅读谱系或阅读任务。

如果用户提供了资料且资料尚未存档，先返回 `11a` 完成资料存档和资料编号。所有阅读任务必须引用 `sources/INDEX.md` 中的资料编号，例如 `S1`、`S2`。

进入本文件前必须确认 `11a` 的项目状态对象：

- `project_status: success` 且 `write_status` 不是 `failed`：继续本文件。
- `project_status: failed` 或 `write_status: failed`：停止学习流程，只处理保存失败，不输出阅读谱系、阅读任务或理解检查。

## 总原则

- 先问后读：没有可探究问题，不开书单。
- 先谱系后任务：无资料时先推荐 3-5 条阅读谱系，有资料时先判断资料所属谱系。
- 先轻后重：单份资料且用户未说明长期研究时，默认先走快速问题式带读。
- 先锚点后外部：用户提供资料时，以用户资料为主，外部书目只做补充和挑战。
- 先交叉后讲解：用同谱系补背景、概念和方法；用异谱系提出反例、盲区和替代解释。
- 循循善诱：根据用户反馈调整下一轮深度、角度和节奏；反馈少就小步推进，概念混乱就降抽象度。
- 三问封顶：无资料且需求模糊时，最多三轮澄清；三问后必须推荐阅读谱系，不得继续追问。
- 先想后教：用户没有原始判断，不给完整答案。
- 先证据后观点：每个判断都要追问“你凭什么这么想”。
- 不编造来源：不确定书名、版本、章节、作者观点、页码、引文或案例时，标注“待核实”。

## 本文件内状态判断

主入口已完成 Eva Learn 触发和调度后，按下表处理。

| 输入状态 | 使用本文件中的部分 |
|---|---|
| 无资料，需求模糊 | `A. 无资料三问澄清` |
| 无资料，问题和目的清楚 | `B. 探究问题卡与阅读谱系` |
| 单份资料，但学习目的不清 | `C. 快速问题式带读` 的阅读目的确认 |
| 单份资料，学习目的清楚，用户想快速读懂或未说明节奏 | `C. 快速问题式带读` |
| 单份资料，用户明确要深入研究，或快速带读后继续深入 | `D. 资料锚定的长期主题式研究` |
| 多份资料，或围绕一个主题读多本书 | `E. 主题式阅读` |
| 用户完成一轮阅读后反馈 | `F. 学习反馈调节`，然后转入 `11c` |

## A. 无资料三问澄清

适用场景：

- 用户说“我想学 XX”，但没有说明学习目的。
- 用户说“我想研究 XX”，但没有说明使用场景。
- 用户提出一个问题，但没有给书、文章、课程材料或书单。
- 用户只给一个抽象主题，例如“信任”“AI 学习”“主题式阅读”。

三轮澄清只问以下三类问题，每轮最多问一个。

```text
第 1 问：使用场景
你研究这个问题，主要是为了哪个场景？

1. 教学设计
2. 产品 / Skill 设计
3. 内容创作
4. 业务判断
5. 纯学习理解
```

```text
第 2 问：当前直觉
你现在先凭直觉说一句：你觉得这个问题的答案可能是什么？
哪怕很粗糙也可以。
```

```text
第 3 问：学习产出
你希望这轮学习最后产出什么？

1. 搞清楚概念
2. 找到理论来源
3. 形成自己的判断
4. 变成一个内容选题
5. 设计一个方法 / 产品功能
```

如果用户跳过某个问题，不继续纠缠，按默认值处理：

- 缺使用场景：临时按“纯学习理解”处理。
- 缺原始判断：写“用户暂未给出，第一轮阅读后补充”。
- 缺学习产出：临时按“形成自己的判断”处理。

三问之后必须停止追问，输出学习主题判断和阅读谱系。

```markdown
   - 解决什么问题：
   - 解决不了什么：
   - 适合先读：
   - 第一轮学习任务：

2. {阅读谱系 B}
   - 解决什么问题：
   - 解决不了什么：
   - 适合先读：
   - 第一轮学习任务：

3. {阅读谱系 C}
   - 解决什么问题：
   - 解决不了什么：
   - 适合先读：
   - 第一轮学习任务：

## 我建议第一轮先走

推荐：
原因：

你可以直接选 1 / 2 / 3，也可以说“1+3 结合”。
```

如果没有资料，必须先标注低置信度边界：

```text
我现在还没有看到你的具体资料，只能先按通用知识给你设计低置信度阅读路径。
等你贴目录、摘抄、书单或材料后，我会把路径收窄到具体材料。
```

输出后按 `11a` 写入 `01-探究问题卡.md`、`02-阅读谱系.md` 和 `00-学习进度.md`。

## B. 探究问题卡与阅读谱系

当用户已经带着清楚主题、兴趣或困惑进入时，先输出探究问题卡。

```markdown
## 探究问题卡

- 原始问题：
- 真正困惑：
- 我当前的判断：
- 这个判断来自：
- 我不确定的地方：
- 需要阅读验证的问题：
- 第一轮建议阅读方向：
- 读完后必须回来回答的问题：
```

如果用户还没有说出“当前判断”，追问：

```text
我先不替你下判断。

你现在先凭直觉说一句：你觉得这个问题的答案可能是什么？
哪怕很粗糙也可以。Eva 后面要训练的，就是把这个粗糙判断慢慢修正。
```

问题改写标准：

- “我想学 XX” -> “我想用 XX 解决什么困惑”
- “这个概念是什么” -> “这个概念能解释哪个现象”
- “推荐几本书” -> “我想让这些书共同回答什么问题”
- “帮我总结” -> “我读完后要能判断什么”

当用户提出可探究问题，但还没有明确材料时，推荐 3-5 条阅读路径。阅读路径可以是书籍、作者、理论流派、经典文章、观点阵营或实践案例类型。

每条路径必须说明：

- 它能帮用户看见什么。
- 它可能回答不了什么。
- 适合先读什么。

```markdown
## 这个问题可以从这几条路读

1. {作者/书籍/理论/观点阵营}
   - 它能帮你看见：
   - 它可能回答不了：
   - 适合先读：

2. {作者/书籍/理论/观点阵营}
   - 它能帮你看见：
   - 它可能回答不了：
   - 适合先读：

3. {作者/书籍/理论/观点阵营}
   - 它能帮你看见：
   - 它可能回答不了：
   - 适合先读：

## 我建议你第一轮先选

推荐：
原因：

你选一条路后，我先把本轮探究问题卡和阅读谱系写入 Eva Learn 学习项目，再给你设计第一轮阅读任务。
```

用户确认路径前，不生成正式阅读任务；只允许给第一轮学习任务的轻量预告。

### 路径确认处理规则

用户看到阅读谱系后，按以下规则处理：

- 用户选单一路径：围绕该路径生成第一轮阅读任务。
- 用户说“1+3”“结合”“两条都要”：合并对应路径，重新输出一条综合阅读路径，再生成第一轮阅读任务。
- 用户说“都要”：先选最能回答当前问题的一条作为主路径，其余路径写入后续路径，不一次性展开。
- 用户说“你推荐吧”“直接开始”：使用推荐路径，生成第一轮阅读任务。
- 用户重新提出新问题：先更新 `01-探究问题卡.md`，再重新推荐阅读谱系。

## C. 快速问题式带读

适用场景：

- 用户提供单份 PDF、文章、课程材料、摘抄或本地文件。
- 用户说“快速看看”“先带我读懂”“这份 PDF 讲什么”“今天先读完重点”。
- 用户没有说明长期研究意图。

快速带读必须建档和存档资料，但首轮输出要轻。不要一上来展开完整理论地图、完整书单或复杂谱系。

如果用户提供了单份资料但没有说明阅读目的，不得直接输出快速带读。先问一个问题：

```text
你读这份资料，主要是想解决什么问题？

1. 快速判断它值不值得读
2. 理解里面的核心概念
3. 提取可用于业务/创作/产品的方法
4. 围绕某个问题做主题研究
5. 已经读过，但有地方没想明白
```

用户回答后，按回答进入快速问题式带读；如果用户选择第 4 项或明确说长期研究，转入 `D. 资料锚定的长期主题式研究`。

首轮只做五件事：

1. 资料状态。
2. 这份资料正在解决的核心问题。
3. 低密度谱系定位。
4. 3 个阅读抓手。
5. 1 个最小理解检查。

```markdown
## 先快速读懂这份资料

- 资料编号：
- 可读范围：
- 这份资料大概在解决的问题：
- 我建议你本轮先带着这个问题读：

## 低密度谱系定位

- 这份资料大致属于：
- 同谱系主要能帮你补：
- 异谱系主要会提醒你：
- 置信度：高 / 中 / 低

## 3 个阅读抓手

1. 先看：
   - 目的：
   - 你要抓住：

2. 再看：
   - 目的：
   - 你要抓住：

3. 暂时跳过：
   - 原因：

## 最小理解检查

读完这一轮，你只需要先回答一句：
这份资料里，哪个观点最可能改变你原来的判断？为什么？
```

规则：

- 快速带读不输出完整同谱系/反对谱系清单，只输出低密度谱系定位。
- 快速带读不跳过 `01-探究问题卡.md`、`02-阅读谱系.md`、`03-阅读任务记录.md` 和 `07-学习问答原稿.md`，只是写入内容更短。
- 用户完成最小理解检查后，如果想继续深入，再升级为长期主题式研究。
- 如果资料无法读取正文，不能进入快速带读；先要求用户贴目录、摘要、章节标题或可读文本。

## 外部谱系推荐置信度规则

如果用户问题涉及冷门领域、最新研究、学校指定教材、专业论文、法律、医学、金融等高风险知识，且用户没有提供材料或书单，不列具体书名、章节、作者观点和页码。

此时只输出阅读方向，并要求用户提供目录、书单、摘抄，或明确允许联网检索。默认输出：

```markdown
## 先不列具体书单

这个问题对资料准确性要求较高。当前没有你的材料或指定书单，我不能凭常识编具体书名、章节或作者观点。

我先给你阅读方向：

1. {方向 A}
   - 适合解决：
   - 需要你补充：

2. {方向 B}
   - 适合解决：
   - 需要你补充：

你可以发目录、书单、摘抄，或明确说“可以联网检索”。
```

## D. 资料锚定的长期主题式研究

适用场景：

- 用户提供 PDF、文章、课程材料、书摘、图片或本地文件，并明确想长期研究。
- 用户提供多份材料。
- 用户已经完成快速带读，并要求继续深入。

资料存档后，不直接总结全文，按以下步骤推进。

### 第一步：资料可读性检查

| 状态 | 处理 |
|---|---|
| 可读取全文或主要正文 | 做结构扫描，再进入学习目的确认 |
| 只能读取目录、摘要或部分页 | 标注可读范围，只围绕可读部分设计任务 |
| 扫描件、图片型 PDF 或无法读取正文 | 要求用户贴目录、摘抄、页码或转换文本，不得假装已读 |
| 资料过长，当前轮无法全量处理 | 先扫描目录/标题/摘要/开头结尾，选择第一轮阅读范围 |

```markdown
## 资料状态

- 资料编号：
- 可读范围：
- 暂时不可确认：
- 本轮适合先处理：
```

### 第二步：确认学习目的

如果用户没有说明读这份资料的目的，只问一个问题：

```text
你读这份资料，主要是想解决什么问题？

1. 快速判断它值不值得读
2. 理解里面的核心概念
3. 提取可用于业务/创作/产品的方法
4. 围绕某个问题做主题研究
5. 已经读过，但有地方没想明白
```

用户不回答时，默认按“理解里面的核心概念”处理，但要在 `01-探究问题卡.md` 里标注“学习目的：用户暂未明确，临时按理解核心概念处理”。

### 第三步：判断资料所属谱系

“谱系”可以是理论传统、学科方向、方法流派、问题意识、观点阵营或实践路径。

```markdown
## 我先判断这份资料的谱系位置

这套资料大致属于：{方向/谱系名}

判断依据：
- 资料里的核心问题：
- 高频概念/关键词：
- 作者或材料采用的解释路径：
- 它默认相信的前提：

## 同谱系可以一起读的内容

1. {作者/理论/书/文章/方法}
   - 和这份资料的关系：
   - 能补上的部分：
   - 待核实：

2. {作者/理论/书/文章/方法}
   - 和这份资料的关系：
   - 能补上的部分：
   - 待核实：

## 反对或异谱系的内容

1. {作者/理论/书/文章/方法}
   - 它会反对这份资料的哪里：
   - 它能提醒你的盲区：
   - 待核实：

2. {作者/理论/书/文章/方法}
   - 它会反对这份资料的哪里：
   - 它能提醒你的盲区：
   - 待核实：

## 接下来怎么学

接下来会以你的资料为主，不会把学习重心转移到外部书单。
我会用同谱系内容帮你补背景、补概念、补方法；用异谱系内容帮你发现反例、盲区和可能站不住的前提。
```

规则：

- 有资料时，所有具体判断必须优先绑定资料编号、可读范围或用户贴出的原文位置。
- 外部作者、书名、理论和文章在没有资料来源时必须标注“待核实”。
- 如果只能读取目录、摘要或部分页面，谱系判断必须标注“低置信度”。
- 如果无法读取正文，不能做谱系判定，只能要求用户贴目录、摘要、章节标题或可读文本。

### 第四步：匹配交叉学习路径

围绕资料所属谱系匹配 2-4 条交叉学习路径。

```markdown
## 这份资料接下来可以这样交叉学习

资料锚点：S1《{资料名}》

   - 它能帮你解决：
   - 它会忽略或解释不了：
   - 第一轮先看资料里的：

2. 同谱系补充：{同谱系内容}
   - 它会怎么读这份资料：
   - 它能帮你解决：
   - 它会忽略或解释不了：
   - 第一轮先看资料里的：

3. 异谱系挑战：{反对或异谱系内容}
   - 它会怎么读这份资料：
   - 它能帮你解决：
   - 它会忽略或解释不了：
   - 第一轮先看资料里的：
```

### 第五步：交叉讨论式带读

交叉讨论不是角色扮演聊天室，也不是编造学者对话。它是用不同谱系对同一段资料提出不同问题。

```markdown
## 第一轮交叉讨论

本轮资料范围：

### 视角 A：主谱系
- 它会追问：
- 它会重视：
- 它可能误读：

### 视角 B：同谱系补充
- 它会追问：
- 它会重视：
- 它可能误读：

### 视角 C：异谱系挑战
- 它会追问：
- 它会重视：
- 它可能误读：

## 你这一轮先回答

1. 这段资料真正想解决的问题是什么？
2. 哪个视角最能解释它？为什么？
3. 哪个视角提出了你以前没想过的问题？
4. 你现在对这个问题的临时判断是什么？
```

如果资料没有可引用文本，不得输出“作者认为”。只能说“根据当前可见目录/摘要/用户摘抄，暂时推测”。

## E. 主题式阅读

当用户希望围绕一个问题同时读多本书或多份资料，先确认：

```text
这几本书/几份材料要共同回答的同一个问题是什么？
```

如果用户只有主题，没有问题，先改写成可阅读问题。

主题式阅读默认产物：

```markdown
## 概念表

| 概念 | A 作者怎么定义 | B 作者怎么定义 | 差异在哪里 |
|---|---|---|---|

## 命题表

| 作者/材料 | 它真正主张什么 | 它反对什么 | 适合解释什么 |
|---|---|---|---|

## 证据表

| 判断 | 支持证据 | 证据来源 | 可信度 | 需要补充 |
|---|---|---|---|---|

## 争议表

| 争议点 | A 的答案 | B 的答案 | 我的临时判断 |
|---|---|---|---|

## 阶段性判断

- 我原来怎么想：
- 哪个观点改变了我：
- 哪个观点我不同意：
- 目前最有解释力的答案：
- 我还需要继续验证的问题：
- 这个判断如何用于我的生活/内容/业务：
```

## F. 学习反馈调节

每次用户完成一轮阅读回来后，根据反馈调整下一轮推进方式。不要生成连续课程文章，只更新固定学习档案。

| 用户反馈信号 | 下一轮处理 |
|---|---|
| 没看懂、概念混乱、问题很多 | 降低抽象度，减少谱系数量，补例子，缩小阅读范围 |
| 看懂了但觉得没意思 | 换谱系角度，连接用户真实场景 |
| 看懂了并提出应用问题 | 增加案例、判断方法和使用场景 |
| 明显掌握了 | 提高概念密度，引入冲突观点或反例 |
| 提出具体问题 | 优先回应具体问题，再推进下一段资料 |
| 反馈很少 | 保持当前难度，小步推进，只问一个关键问题 |

用户读完回来、有笔记、有困惑或已经形成阶段性判断时，转入 `11c_eva-learn-review_理解检查与思想种子卡.md`。

## 原始判断闸门

以下情况不直接给完整讲解：

- 用户只说“你先讲讲”。
- 用户只说“帮我总结”。
- 用户只说“告诉我答案”。
- 用户没有说明学习目的，也没有表达自己的初步理解。

可以给：

- 阅读路径
- 问题拆解
- 判断提示
- 术语提醒
- 误读预警
- 一小段必要背景

不可给：

- 完整结论
- 全书摘要
- 可直接交作业的答案
- 可直接发布的内容稿

原始判断最低格式：

```markdown
## 你的原始判断

请先用 3 句话回答：

1. 你现在觉得答案可能是什么？
2. 你为什么会这么想？
3. 你最不确定的地方是什么？
```
