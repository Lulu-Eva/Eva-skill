# Eva Learn 子模块：理解检查与思想种子卡

本文件处理读后阶段：理解检查、纠偏、判断版本、思想种子卡和下游衔接。

如果当前主题有学习项目文件夹，先读 `11a_eva-learn-project_学习项目与资料存档.md` 恢复进度和资料索引。

## 使用时机

- 用户读完材料回来。
- 用户贴读书笔记、划线、摘抄、困惑。
- 用户说“我读完了，你帮我看看理解对不对”。
- 用户已经形成阶段性判断。
- 用户想把学习结果转成内容。

## 理解检查

用户读完回来，先检查四件事：

1. 复述：能不能用自己的话说清楚。
2. 举例：能不能举一个自己的真实例子。
3. 反例：知不知道这个观点解释不了什么。
4. 证据：知道这个判断凭什么成立。

默认输出：

```markdown
## 我先检查你的理解

- 你理解准确的地方：
- 你可能跳过的地方：
- 你有点误读的地方：
- 你现在最值得继续追问的问题：

## 我只补这一处

{只针对一个最关键卡点讲解，不展开成大课。}

## 你下一步回答

请你补一句：
这个观点如果放到你的真实处境里，能解释什么？解释不了什么？
```

纠偏只纠最关键的一处。用户理解很好，就提高问题难度，不继续讲基础。

## 判断版本

每完成一轮阅读或思考，沉淀：

```markdown
## 判断版本 v{n}

- 本轮问题：
- 我原来的判断：
- 本轮阅读/思考给我的新证据：
- 我修正了什么：
- 我仍然不确定什么：
- 下一轮要验证什么：
```

判断版本不是最终结论。它是当前最诚实的阶段性理解。

如果用户想继续深入，基于“我仍然不确定什么”回到 `11b` 设计下一轮阅读任务。

## 思想种子卡

只有当用户完成至少一轮问题澄清、原始判断和阅读/思考修正时，才输出思想种子卡。

```markdown
## 思想种子卡

- 主题：
- 真实困惑：
- 核心判断：
- 支持证据：
- 反方观点：
- 个人经历连接：
- 适合表达的人群：
- 可以延展的内容角度：
- 当前成熟度：萌芽 / 可进入内容入口 / 可进入正文前校验
- 建议下游模块：
```

成熟度判断：

| 成熟度 | 判断标准 | 下一步 |
|---|---|---|
| 萌芽 | 有兴趣，但问题和判断还模糊 | 继续提问式学习 |
| 可进入内容入口 | 有清楚判断和真实经验，但人群、用户疑问或标题/第一句话入口未定 | 交给 `/eva-audience-finder`、`/eva-title` 或 `/eva-script` 开头分支 |
| 可进入正文前校验 | 判断、证据、人群、用户疑问、标题交接卡或第一句话交接卡都清楚 | 交给 `/eva-script` 做正文逻辑链和正文路线图 |

思想种子卡必须保留“不确定处”。不要把阶段性判断包装成绝对真理。

禁止使用“可成稿”作为思想种子卡成熟度。思想种子卡最多只能说明“可进入内容入口”或“可进入正文前校验”，不能承诺直接成稿。

## 内容链路硬闸门

思想种子卡只是上游思想材料，不是标题交接卡、第一句话交接卡或正文任务卡。

进入内容链路前，必须先经过：

```text
思想种子卡 -> 人群/用户疑问判断 -> 标题或第一句话入口 -> 正文链路
```

只有判断、证据、人群、用户疑问、标题交接卡或第一句话交接卡都清楚，才可以建议进入 `/eva-script`。

如果任一项不清楚，先交给 `/eva-audience-finder` 或 `/eva-title`。

禁止：

```text
思想种子卡 -> 直接生成完整稿
```

## 保存与衔接

如果当前主题已建学习项目：

- 判断版本追加到 `05-判断版本.md`。
- 思想种子卡追加到 `06-思想种子卡.md`。
- 更新 `00-学习进度.md` 的当前阶段、下一步和判断版本索引。

如果用户明确说“保存、沉淀、记下来、做成卡片”，可以建议交给 `/eva-memory` 或在当前项目的 `eva-memory/` 中保存。

推荐保存对象：

- `judgment-version-card`：判断版本。
- `thought-seed-card`：思想种子卡。

优先保存思想种子卡，不保存泛泛读书摘要。

## 禁止

- 不直接写完整内容稿。
- 不把思想种子卡当成标题交接卡。
- 不把阶段性判断包装成绝对真理。
- 不编造用户经历、书中案例、引文或页码。
