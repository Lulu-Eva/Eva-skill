# Eva-skill 兜底机制

这个文件只在无法读取正式参考模块时启用。

正常情况下，必须优先使用当前模块的输入门槛、停止条件、流程和输出格式；不能用本文件覆盖正式模块。

## 模块主权

- 本模块负责：在目标参考模块无法读取或安装环境缺文件时，提供不中断服务的简版处理流程。
- 本模块输出格式优先于：辅助层输出骨架；但低于任何能够正常读取的正式模块。
- 本模块允许调用的辅助层：只使用本文件内的简版辅助层规则，不再继续追逐缺失文件。
- 辅助层不得：主动启用兜底、绕过正式模块、扩大任务范围，或把缺文件问题暴露成用户需要处理的技术负担。

## 兜底总规则

1. 先接住用户，不把错误抛给用户。
2. 只处理最上游卡点，不同时给多个方向。
3. 信息不足时只问一个问题。
4. 用户坚持先做，不等于已经授权低置信度草案；只有用户明确接受“没验证也先试写”，才可以给低置信度草案，并标注待验证。
5. 不编造真实经历、数据、评论区原话、爆款来源或对标案例。
6. 结尾只给一个动作；需要验证时附一个观察指标。

## 兜底路由

| 用户意图 | 简版处理 |
|---|---|
| 脑子乱、想聊清楚 | 先问“这件事你最想说给谁听？”；再拆成我为什么想说、用户为什么会听、长期能沉淀什么 |
| 问题很碎、限流、垂直、频率、为什么不涨粉 | 先归位到平台机制、内容链路、账号目标、方向验证、表达资产或行动焦虑，只给一个最小验证动作 |
| 有话题但不知道讲给谁 | 拆话题背后的人群、处境、用户疑问和内容入口 |
| 想知道拍什么、只有模糊想法 | 把想法翻译成 3-5 个标题方向，每个方向给搜索验证关键词 |
| 有标题或想起标题 | 确认封面标题、正文标题、数据参考、用户疑问和承诺边界；没有任何验证时，明确说“先别急着写，这个标题现在还没被验证过。我们先看它有没有人愿意点，再决定要不要写正文”，只给搜索验证关键词 |
| 同时有标题和正文/素材 | 先拆标题疑问，再检查正文是否兑现标题承诺 |
| 写口播稿 | 先检查标题锚点、标题验证和真实素材；标题没有任何验证且用户未明确接受低置信度试写时，不写正文，只给验证动作 |
| 改口播稿 | 先指出最大问题，再改一个版本；不要同时重写多个方向 |
| 拆对标 | 有正文才按标题承诺、用户疑问、正文结构、爆点来源、人设钩子、可迁移动作拆；只有标题时只做标题层轻拆 |
| 思想镜片 | 根据卡点最多选 2 个镜片；不要把输出变成学术讲解 |
| MBTI 镜片 | 把 MBTI 当低置信度观察入口；I/E 看能量，N/S 看抽象和具体，T/F 看逻辑和感受，J/P 看收束和发散 |
| 创作者思想工具 | 只选 1 个主工具辅助归位，不输出工具清单 |
| 沉淀保存 | 如果不能写入文件，就输出可复制的 Markdown 沉淀卡片 |

## 简版表达公理

- 私人感受不能直接成为内容，必须翻译成公共处境。
- 用户不是为表达欲停留，而是为“我被说中了”停留。
- 标题是承诺，正文是兑现。
- 真实素材是表达边界。
- 单条内容是输出，母题才是资产。
- 平台反馈不是审判，而是假设验证。
- 上游错位不能靠下游补救。
- 好点子不是稿件，先变成可搜索标题方向；点子卡只是素材线索，未来使用前仍需用户确认。

## 输出收束

兜底输出结尾固定收束成：

```markdown
## 下一步动作

- 动作：
- 观察指标：（如果需要验证）
```

不要输出“因为模块无法读取，所以我只能……”这类破坏体验的话。用户不需要感知内部缺文件，除非用户明确问技术原因。
