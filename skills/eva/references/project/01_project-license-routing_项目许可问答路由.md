# Eva-skill 项目许可问答路由

只有用户明确询问 Eva-skill 本身的许可证、商用范围、修改发布、输出变现、隐私、法律风险、责任边界、商标、官方身份或第三方材料时，才读取本文件。普通 Think、Create、Brief、Learn、Review、Lens、Preflight 或其他 Eva 业务任务不得加载本文件及法律真源。

本文件只负责找到法律真源、控制最小读取范围和处理“许可问答＋业务执行”混合请求，不替代 `LICENSE`、`LEGAL_NOTICE.md`、`TRADEMARKS.md` 或 `THIRD_PARTY_NOTICES.md` 的实质条款。

## 一、按运行布局解析真源

不得跨项目搜索法律文件。按以下顺序判断，命中一种布局后停止：

| 运行布局 | 识别方式 | 法律真源 |
|---|---|---|
| SkillHub / 一体化包 | 对应文件与当前 `SKILL.md` 位于同一目录 | `LICENSE`、`LEGAL_NOTICE.md`、`TRADEMARKS.md`、`THIRD_PARTY_NOTICES.md` |
| GitHub 源码仓库 | `../../.claude-plugin/marketplace.json` 存在 | `../../LICENSE`、`../../LEGAL_NOTICE.md`、`../../TRADEMARKS.md`、`../../THIRD_PARTY_NOTICES.md` |
| 逐个 Skill 安装 | 以上两种布局均不成立 | `references/project/00_project-info_项目身份与许可.md` 中的精简发行说明 |

同目录文件优先于源码仓库路径。使用 `../../` 前必须验证仓库结构标记，避免误读其他项目的法律文件。逐个 Skill 安装缺少完整第三方清单时，依据精简发行说明回答，并建议用户到官方仓库核对完整清单。

所需真源不存在时，明确说明当前安装缺少对应法律真源；不得跨目录猜测，也不得用模型常识补写 Eva-skill 的授权条款。

## 二、最小读取规则

只读取足以回答用户实际问题的文件和小节：

- 问许可证、非商业使用、分享、修改版或衍生发布：读取 `LICENSE`，必要时追加 `LEGAL_NOTICE.md` 的“项目主体许可”和商业边界。
- 问个人创作者最终内容能否变现、企业使用、团队使用或客户交付：读取 `LEGAL_NOTICE.md` 的“用户最终内容商业化额外许可”及与该用途直接相关的边界。
- 问额外许可适用哪个版本、以后能否撤回、违约如何终止或恢复、旧版本和既有最终内容是否受未来变化影响：只读取 `LEGAL_NOTICE.md` 的“适用版本、持续效力与补救”。
- 问输入材料、数据处理、AI 标识、案例使用、发布责任、修改版责任、免责或法律风险：只读取 `LEGAL_NOTICE.md` 的对应小节。
- 问名称、Logo、官方版、认证版、合作或背书身份：读取 `TRADEMARKS.md`；只有需要解释版权许可时才追加 `LICENSE`。
- 问项目是否包含第三方代码、提示词、素材，或某项内容能否再次许可：读取 `THIRD_PARTY_NOTICES.md`，必要时再读取对应上游许可。

问题已经由一个真源充分回答时，不继续加载其他法律文件。纯许可或法律问答完成后停止，不进入 Eva 业务模块。

## 三、回答边界

- 不得只根据“CC”“开源”“免费”等词推断授权；免费不等于非商业，免费发布也不自动落入非商业许可。
- 不得只根据个人、企业、营利或非营利身份判断是否商业使用，也不得把“不在个人创作者额外许可内”直接等同于“必然需要授权”；先判断实际用途、受保护材料和依法无需授权的情形。
- 不得承诺用户拥有全部 AI 输出版权。只能依据项目额外许可说明 Eva-skill 项目方授予的范围，并提醒第三方权利、平台规则和适用法律仍可能影响使用。
- 普通最终内容的品牌二次使用原则上由品牌与创作者之间的合同确定；不得仅因创作过程中使用过 Eva-skill 就要求品牌另行取得 Eva-skill 授权。
- 不把一般信息说成针对用户个案的法律意见；涉及合同、争议或具体责任判断时，说明应向适用法域的律师确认。
- 不根据 Skill 名称、平台作者栏、模型记忆或非官方转载补造许可、商标或官方合作关系。

## 四、许可问答与业务任务混合请求

同一句同时包含许可问题和 Eva 业务任务时，先判定用途，再决定是否执行：

1. **真源明确允许**：用一句话说明适用边界，再按唯一业务意图正常路由一次。
2. **用户明确说明已有适用于该用途的书面商业授权**：说明将按用户陈述的授权前提继续，再路由一次；不替用户验证授权文件的真伪或范围。
3. **真源明确该用途不在额外许可内，且其实际使用涉及受保护材料、不符合标准 CC 或依法无需授权的情形，用户又未说明已有书面授权**：只说明需要另行授权并停止，不进入 Create、Think、Brief、Link 或其他 Eva 业务入口。
4. **用途不清，是否获准会改变能否执行**：只问一个最小边界问题，本轮不执行 Eva 业务任务。

不得出现“先确认该用途需要授权且用户没有授权，再继续用 Eva 完成同一项任务”的行为。客户交付、企业或团队经营性生产、商业化 Eva-skill 本体及其他不在额外许可内的用途，应先按真源判断是否实际需要授权；只有确认需要且用户未获授权时，才必须停在本路由。
