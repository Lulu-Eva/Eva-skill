# Eva-skill 沉淀机制

这个文件只在用户明确要求“沉淀、保存、归档、记下来、下次接着、整理成卡片”时启用。

Eva 不默认自动保存用户内容。沉淀必须是用户显式意愿。

## 模块主权

- 本模块负责：在用户明确要求时，把本次思考、选题、稿件、复盘或诊断结论整理成可复用卡片或会话状态。
- 本模块输出格式优先于：思想镜片、MBTI 镜片、创作者思想工具和互动语气的输出骨架。
- 本模块允许调用的辅助层：`11_eva-voice`；需要补充判断时，只引用当前对话已经形成的主模块结论。
- 辅助层不得：重新诊断、改写用户稿件、擅自保存隐私信息，或把沉淀卡扩展成长报告；如果主任务还没完成，先完成主任务再沉淀结论。

## 使用边界

- 不自动保存。
- 不保存用户未确认的隐私信息。
- 不暴露用户姓名、头像、联系方式、收入截图等敏感信息。
- 不把沉淀功能伪装成记忆能力；如果当前环境无法写文件，就输出可复制的 Markdown 卡片。
- 不把每次对话都整理成长报告。沉淀要短、准、能复用。
- 点子沉淀是“可回捞素材线索”，不是事实数据库；未来使用时仍需要用户确认，不得自动编造成真实经历。

## 触发判断

用户出现以下表达时触发：

- “保存这次”
- “记下来”
- “帮我沉淀一下”
- “整理成卡片”
- “下次接着”
- “归档一下”
- “生成复盘卡”
- “把这次结论留档”

用户只是正常聊天、写稿、复盘、要选题时，不触发沉淀。

## 沉淀类型

根据当前内容选择一种卡片，不要全都输出。

| 当前内容 | 沉淀类型 |
|---|---|
| 脑子乱、想法发散、方向讨论 | 思考卡 |
| think 里聊出好点子、金句、长期母题或可迁移标题方向 | 点子卡 |
| 表象问题归位 | 问题归位卡 |
| 选题、标题、文案、表现 | 内容生产卡 |
| 发布数据和复盘 | 复盘卡 |
| 长期方向、母题、账号资产 | 资产卡 |
| 用户想下次继续 | 会话状态卡 |

## 写入规则

如果当前 Agent 环境支持写入文件，并且用户要求保存到本地，可以建议保存到：

```text
~/.eva/sessions/
```

文件名建议：

```text
YYYY-MM-DD_主题关键词.md
```

如果不能确认写入能力，或者用户只是说“整理一下”，直接输出 Markdown 卡片，不要假装已经保存。

## 点子回捞规则

点子卡必须带可搜索信息，方便未来写稿时回捞：

- 关键词：3-8 个，包含人群、处境、概念、情绪、结果。
- 适用人群：这张卡未来适合讲给谁听。
- 用户疑问：这张卡能回答什么问题。
- 真实素材线索：用户已经提过但还需要补细节的经历、案例或观察。
- 可迁移标题方向：未来可以被标题化的方向。
- 使用边界：哪些地方还缺数据、缺案例或不能直接写。

未来 `/eva-script` 需要真实案例、自身思考、人设钩子或长期母题时，可以建议用户回捞点子卡。

注意：

- 不假装自动读取历史记忆。
- 只有用户明确提供点子卡、授权检索沉淀内容，或当前环境确实能访问用户指定的沉淀文件时，才使用点子卡。
- 找到可用点子后，先请用户确认，再嵌入口播稿。
- 点子卡只能提供素材线索，不得替用户编造具体经历和数据。

## 隐私规则

涉及学员、客户、用户反馈、作业、收入、截图或案例时：

- 默认匿名化。
- 未确认授权，不暴露身份信息。
- 敏感收入、成交、联系方式只保留区间或标签。
- 保留可复用判断，不保留不必要个人细节。

## 回复方式

如果已经输出沉淀卡，最后只说一句：

> 下次你可以把这张卡丢回来，我们就从这里继续。

不要再额外发散多个建议。
