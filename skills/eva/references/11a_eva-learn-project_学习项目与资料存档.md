# Eva Learn 子模块：学习项目与资料存档

本文件只处理学习项目、资料存档和进度恢复。

不要在本文件里执行提问式学习、主题式阅读、理解检查或内容转化；这些分别交给 `11b` 和 `11c`。

## 使用时机

仅在用户已经主动触发 `eva-learn` 后读取本文件。

读取本文件的场景：

- 用户刚进入 Eva Learn，且已经可以确定主题名。
- 用户说“继续 eva-learn”“接着上次读”“继续这个主题”。
- 用户提供书摘、文章、课程材料、PDF、图片或本地文件路径。
- 当前任务需要保存探究问题卡、阅读谱系、阅读任务、理解检查、判断版本、思想种子卡或学习问答原稿。

只要用户进入 Eva Learn，就必须建档。没有“短问题不建档”“一次性带读不建档”“低置信度路径不建档”的分支。

唯一允许延迟建档的情况：还无法确定主题名。此时只问一个建档必需问题：

```text
这个 Eva Learn 项目我先用哪个主题名保存？
```

## 建档判定

必须建档：

- 用户明确触发 `eva-learn`，并给出主题、书名、材料名或学习问题。
- 用户提供本地文件、PDF、多份材料、书摘、文章、课程资料或图片。
- 用户选择了阅读路径、学习路径、作者谱系或主题式阅读方向。
- 用户生成了探究问题卡、阅读谱系、阅读任务、理解检查、判断版本或思想种子卡。
- 用户说“继续 eva-learn”，但当前主题还没有进度文件。

不得以以下理由跳过建档：

- 一次性问一本书值不值得读。
- 只要一个低置信度阅读路径。
- 只做一次短材料带读，没有后续继续意图。
- 用户没有明确说“下次继续”。
- 本轮还没有完整阅读任务。

用户后续是否继续学习由用户决定；系统职责是在 Eva Learn 开启时留下可复查、可恢复的学习档案。

## 建档执行协议

需要建档时，必须按以下顺序执行。不得只在对话里说“已保存”，却没有真实创建文件或记录状态。

```text
1. 确定主题名。
2. 定位保存目录。
3. 创建固定文件结构。
4. 处理用户提供的资料。
5. 更新 sources/INDEX.md。
6. 更新 00-学习进度.md。
7. 按本轮状态写入 01-07 的对应文件。
8. 输出项目状态对象。
9. 告知用户保存路径、资料状态和下一步。
```

### 1. 确定主题名

主题名优先级：

1. 用户明确给出主题名：使用用户原主题名，去掉不适合作为文件夹名的符号。
2. 用户给出问题：压缩成 8-20 个字的主题名。
3. 用户只给书名/资料名：使用书名或资料名。
4. 无法判断：只问一个问题。

```text
这个 Eva Learn 项目我先用哪个主题名保存？
```

不要使用“新建项目”“学习资料”“未命名”作为长期主题名。

如果用户只有模糊主题，例如“AI”“信任”“主题式阅读”，允许先使用临时主题名建档。后续三轮澄清后主题变准确时，不强制重命名文件夹；必须在 `00-学习进度.md` 记录主题修正，保证下次续学能看懂主题演变。

主题修正规则：

- 临时主题名可以保留为文件夹名，避免移动文件导致路径失效。
- 修正后的主题写入 `00-学习进度.md` 的“当前问题”和“主题修正记录”。
- 如果用户明确要求改文件夹名，再在不覆盖旧项目的前提下重命名或新建主题变体。

### 2. 定位保存目录

按“存放位置”规则确定目录后，先检查是否已存在同名主题文件夹：

- 已存在：读取 `00-学习进度.md`，判断是继续旧项目还是新建同名变体。
- 不存在：创建新主题文件夹。
- 同名但主题明显不同：在主题名后追加日期或序号。

如果无法确认是否同一主题，只问：

```text
我找到了一个同名 Eva Learn 项目。你是要接着它学，还是新建一个同名新项目？
```

如果当前目录是 Eva-Skill 仓库本体、安装后的 `skills/eva/` 目录，或明显属于 Skill 源码目录：

1. 先向上查找最近的非 Skill 项目根目录。
2. 如果父级项目根目录可写，使用 `{父级项目根}/eva-learn/{主题名}/`。
3. 只有找不到可写项目根目录时，才使用 `~/Documents/eva-learn/{主题名}/`。
4. 如果仍无法写入，停止学习流程，只输出“建档失败”，要求用户指定可写目录；不得继续输出阅读谱系或阅读任务。

### 3. 创建固定文件结构

新建项目时，必须创建：

```text
00-学习进度.md
01-探究问题卡.md
02-阅读谱系.md
03-阅读任务记录.md
04-理解检查记录.md
05-判断版本.md
06-思想种子卡.md
07-学习问答原稿.md
sources/INDEX.md
sources/原始资料/
```

如果部分文件已存在，不覆盖，只补齐缺失文件。

新建项目时，`01-06` 不得为空文件。必须写入标题和状态：

```markdown
# {主题名}｜探究问题卡

状态：待生成

# {主题名}｜阅读谱系

状态：待生成

# {主题名}｜阅读任务记录

状态：待生成

# {主题名}｜理解检查记录

状态：待生成

# {主题名}｜判断版本

状态：待生成

# {主题名}｜思想种子卡

状态：待生成
```

`07-学习问答原稿.md` 新建时写入标题：

```markdown
# {主题名}｜Eva Learn 学习问答原稿
```

### 4. 处理用户提供的资料

- 本地文件路径：复制到 `sources/原始资料/`。
- 粘贴长文本：保存为 `sources/原始资料/{日期}-粘贴资料.md`。
- 图片、PDF、课件或附件：复制到 `sources/原始资料/`。
- 无法复制或无法写入：不假装成功，在 `sources/INDEX.md` 标记为“待补档”，并在回复里说明。

### 5. 更新资料索引

每处理一份资料，都要追加或更新 `sources/INDEX.md`。

资料编号按 `S1`、`S2`、`S3` 递增；不得复用旧编号指向新资料。

### 6. 更新学习进度

建档完成后，必须更新 `00-学习进度.md` 至少以下字段：

```markdown
- 当前问题：
- 当前阶段：
- 学习节奏：快速问题式带读 / 长期主题式研究
- 当前材料：
- 当前资料编号：
- 最近一次阅读任务：
- 下一步：
- 最近更新：
```

如果本轮还没有阅读任务，`最近一次阅读任务` 写“待生成”，不要空着。

### 7. 写入学习档案

建档后，按本轮已经产生的内容写入对应文件；还没有产生的文件保留标题和“待生成”状态，不留空白文件。

对应关系：

| 文件 | 用途 | 写入时机 |
|---|---|---|
| `01-探究问题卡.md` | 保存真实困惑、原始判断和待验证问题 | 用户完成问题澄清后 |
| `02-阅读谱系.md` | 保存 3-5 条阅读路径、资料所属谱系、同谱系内容、反对/异谱系内容和推荐理由 | 输出阅读谱系或资料所属谱系判定后 |
| `03-阅读任务记录.md` | 保存每轮读什么、为什么读、读完回来回答什么，以及本轮交叉讨论视角 | 布置阅读任务或交叉讨论任务后 |
| `04-理解检查记录.md` | 保存用户读后复述、误读、纠偏和下一步追问 | 完成理解检查后 |
| `05-判断版本.md` | 保存阶段性判断修正 | 生成判断版本后 |
| `06-思想种子卡.md` | 保存可转入表达链路的思想材料 | 生成思想种子卡后 |
| `07-学习问答原稿.md` | 保存完整学习问答过程，方便用户复查课程 | 每次 Eva Learn 对话结束前 |

用户只有主题、没有真实问题时，建档后进入“问题澄清等待态”：

1. `00-学习进度.md` 当前阶段写“问题澄清”。
2. `00-学习进度.md` 最近一次阅读任务写“待生成”。
3. `00-学习进度.md` 下一步写“询问学习目的”。
4. `01-探究问题卡.md` 写入：

```markdown
# {主题名}｜探究问题卡

- 原始问题：{用户原话}
- 真正困惑：待澄清
- 我当前的判断：待补充
- 这个判断来自：待补充
- 我不确定的地方：待补充
- 需要阅读验证的问题：待生成
- 第一轮建议阅读方向：待生成
- 读完后必须回来回答的问题：待生成
```

5. 然后只问一个问题：

```text
你学这个，是想解决哪个真实问题？
```

### 8. 输出项目状态对象

建档、恢复或资料存档后，必须在内部形成以下状态对象，并用它决定是否允许进入 `11b` 或 `11c`：

```markdown
- project_status：success / failed
- project_path：
- current_stage：
- source_index_status：none / created / updated / failed
- write_status：success / partial / failed
- next_allowed_module：11b / 11c / stop
```

执行规则：

- `project_status: success` 且 `write_status: success` 或 `partial`：允许进入 `next_allowed_module`。
- `project_status: success` 但 `source_index_status: failed`：允许继续学习，但必须在回复中说明资料索引未成功更新，并把资料状态标为“待补档”。
- `project_status: failed` 或 `write_status: failed`：`next_allowed_module` 必须写 `stop`，不得继续输出阅读谱系、阅读任务或理解检查。
- 只要写入失败，不得说“已保存”；必须使用“这次还没保存成功”的回复格式。

### 9. 回复用户

建档后回复只说三件事：

```markdown
## 已建档

- 主题：
- 保存位置：
- 已存资料：

## 下一步

{一个阅读或提问动作}
```

如果没有真实写入文件，必须改成：

```markdown
## 这次还没保存成功

- 原因：
- 我先在对话里保留的进度：
- 你可以指定一个可写入目录，我再补建档。
```

## 学习项目原则

Eva Learn 可以跨多次对话推进。用户不需要一次读完所有材料。

学习项目文件夹只记录：

- 现在研究什么问题。
- 这轮读什么材料。
- 用户已经读到哪里。
- 用户的原始判断和判断修正。
- 学习问答的原始过程。
- 下一次回来应该从哪里继续。

不要把它做成连续课程文章，不生成 `01.md`、`02.md` 这类每轮一篇的课程文件。Eva Learn 使用的是固定学习研究档案：`01-探究问题卡.md` 到 `07-学习问答原稿.md` 会被持续追加和更新。

## 存放位置

目录优先级：

1. 用户明确指定目录：使用用户指定目录。
2. 当前目录是项目目录：使用 `当前目录/eva-learn/{主题名}/`。
3. 当前目录不适合保存：使用 `~/Documents/eva-learn/{主题名}/`。

项目目录判断：

- 当前目录有 `AGENTS.md`、`README.md`、`.git`、`skills/`、`知识库/` 任一项，即视为项目目录。
- 如果当前目录是 Eva-Skill 仓库本体、安装后的 `skills/eva/` 目录，或明显属于 Skill 源码目录，不在其中创建学习项目；改用用户指定目录或 `~/Documents/eva-learn/{主题名}/`。

如果无法写入目标目录，不要假装已经保存。直接告诉用户：

```text
建档失败。当前目录和兜底目录都暂时无法写入。
你指定一个可写入目录后，我再继续 Eva Learn。
```

建档失败时，不得继续输出阅读谱系、阅读任务或理解检查。

## 资料存档

如果用户提供文档资料、书摘、文章、课程材料、PDF、图片或本地文件路径，应尽量把原始资料复制或保存到当前学习项目的 `sources/原始资料/` 中，方便下次续学。

资料存档规则：

- 用户提供本地文件路径：复制原文件到 `sources/原始资料/`，保留原文件名。
- 用户粘贴长文本：保存为 `sources/原始资料/{日期}-粘贴资料.md`。
- 用户提供图片、PDF、课件或其他附件：复制到 `sources/原始资料/`，不改动原文件内容。
- 同名文件已存在时，不覆盖，文件名后追加日期或序号。
- 如果当前环境无法复制文件，不要假装已保存；在 `sources/INDEX.md` 记录原路径和“待补档”状态。

`sources/INDEX.md` 固定记录：

```markdown
# 资料索引

| 编号 | 资料名 | 类型 | 来源 | 存档位置 | 用途 | 状态 |
|---|---|---|---|---|---|---|
| S1 |  | 书籍/文章/PDF/课程/摘抄/图片 | 用户上传/本地路径/粘贴 |  | 用来回答哪个问题 | 已存档/待补档/可读性待确认/可读/部分可读/不可读 |
```

每次布置阅读任务时，必须标注使用了哪些资料编号，例如 `S1`、`S2`。

如果资料是 PDF、图片型文件、扫描件或课程课件，必须在 `sources/INDEX.md` 或 `03-阅读任务记录.md` 记录可读性状态：

```markdown
## 资料可读性记录

| 编号 | 可读范围 | 不可确认内容 | 下一步处理 |
|---|---|---|---|
| S1 |  |  |  |
```

## 保存时机

每次完成以下动作后，都要更新 `00-学习进度.md`：

- 建立 Eva Learn 项目。
- 用户提供新的文档资料、书摘、课程材料或本地文件。
- 生成探究问题卡。
- 生成阅读谱系。
- 布置阅读任务。
- 完成理解检查。
- 生成判断版本。
- 生成思想种子卡。
- 完成一次学习问答原稿记录。

对应内容追加到同名记录文件，不要覆盖旧版本。

## 恢复进度

当用户说“继续 eva-learn”“接着上次读”“继续这个主题”时：

1. 先找到对应主题文件夹。
2. 读取 `00-学习进度.md`。
3. 读取 `01-探究问题卡.md`。
4. 读取 `02-阅读谱系.md`。
5. 读取 `03-阅读任务记录.md`。
6. 读取 `sources/INDEX.md`，确认本主题有哪些原始资料。
7. 必要时读取 `04-理解检查记录.md`、`05-判断版本.md`、`06-思想种子卡.md` 和 `07-学习问答原稿.md`。
8. 用 3-5 条告诉用户当前进度、当前问题、最近阅读任务和正在使用的资料。
9. 只推进下一步，不从头开始。

如果找不到对应主题文件夹，只问一个问题：

```text
我没找到这个 Eva Learn 主题的进度文件。你想继续哪个主题？如果有保存目录，也可以直接发给我。
```

## 禁止

- 不把学习项目文件夹做成课程生成器。
- 不自动生成连续学习文章。
- 不覆盖旧资料、旧判断版本或旧任务记录。
- 不把泛泛读书摘要保存成思想种子卡。
- 不跳过建档直接输出阅读任务。
- 不在建档失败后继续学习流程。
- 不创建空白 `01-06` 文件。
- 不把完整学习问答塞进 `03-阅读任务记录.md`；完整问答必须进入 `07-学习问答原稿.md`。
