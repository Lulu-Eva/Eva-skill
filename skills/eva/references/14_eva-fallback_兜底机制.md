# Eva-skill 兜底机制

这个文件只在无法读取正式参考模块时启用。

正常情况下，必须优先使用当前模块的输入门槛、停止条件、流程和输出格式；不能用本文件覆盖正式模块。

## 模块主权

- 本模块负责：在目标参考模块无法读取或安装环境缺文件时，提供不中断服务的简版处理流程。
- 本模块输出格式优先于：辅助层输出骨架；但低于任何能够正常读取的正式模块。
- 本模块允许调用的辅助层：只使用本文件内的简版辅助层规则，不再继续追逐缺失文件。
- 辅助层不得：主动启用兜底、绕过正式模块、扩大任务范围，或把缺文件问题暴露成用户需要处理的技术负担。

## 启用条件

只有出现以下情况，才允许启用兜底：

- 目标 `references/` 文件无法读取。
- 安装环境缺失某个子模块。
- 用户所在 Agent 不支持继续加载参考文件。
- 模块路径异常，但用户已经在等待处理。

不要因为“兜底更短”就主动使用本文件。

## 兜底总规则

1. 先接住用户，不要把错误抛给用户。
2. 只处理最上游卡点，不同时给多个方向。
3. 信息不足时只问一个问题。
4. 用户坚持先做时，可以给低置信度草案，并标注待验证。
5. 不编造真实经历、数据、评论区原话、爆款来源或对标案例。
6. 结尾只给一个动作；需要验证时附一个观察指标。

## 兜底路由

| 用户意图 | 简版处理 |
|---|---|
| 脑子乱、想聊清楚 | 先问“这件事你最想说给谁听？”；再拆成我为什么想说、用户为什么会听、长期能沉淀什么 |
| 问题很碎、限流、垂直、频率、为什么不涨粉 | 先复述表面问题，再归位到平台机制、内容链路、账号目标、方向验证、表达资产或行动焦虑，只给一个最小验证动作 |
| 要选题、今天拍什么、选题库 | 先问目标人群；若用户要求先做，输出 10 个低置信度选题，并给搜索验证关键词 |
| 拆爆款、拆对标 | 按标题、封面、正文结构、爆点来源、人设钩子、可迁移动作六项拆 |
| 起标题封面 | 给 10 个封面标题、10 个正文标题、3 个封面画面方向，并说明点击理由 |
| 写口播稿 | 先做写作前判断，再用“开头留人 -> 用户疑问 -> 三点展开 -> 人设钩子 -> 结尾转粉”写 800-1200 字稿 |
| 改口播稿 | 先指出最大问题，再改一个版本；不要同时重写多个方向 |
| 口播表现 | 把稿子拆成停顿、重音、表情、手势、镜头节奏；没有稿子时先让用户贴稿 |
| 发布复盘 | 按点击率、完播率、互动率、转粉率、选题匹配、人设信任定位最大瓶颈 |
| 思想镜片 | 根据卡点最多选 2 个镜片；不要把输出变成学术讲解 |
| MBTI 镜片 | 把 MBTI 当低置信度观察入口；I/E 看能量，N/S 看抽象和具体，T/F 看逻辑和感受，J/P 看收束和发散 |
| 创作者思想工具 | 只选 1 个主工具辅助归位，不输出工具清单 |
| 沉淀保存 | 如果不能写入文件，就输出可复制的 Markdown 沉淀卡片 |

## 简版表达公理

- 私人感受不能直接成为内容，必须翻译成公共处境。
- 用户不是为表达欲停留，而是为“我被说中了”停留。
- 标题是承诺，正文是兑现。
- 真实素材是表达边界。
- 单条内容是输出，母题才是资产。
- 平台反馈不是审判，而是假设验证。
- 上游错位不能靠下游补救。

## 辅助层兜底

### 思想镜片

- 词不清：维特根斯坦。
- 经历提炼：杜威。
- 表达没生命力：温尼科特。
- 用户听不懂：维果茨基 / 布鲁纳。
- 人设呈现：戈夫曼。
- 媒介形式错位：麦克卢汉。
- 行动逃避：阿德勒。
- 长期杠杆：哈耶克 + 纳瓦尔。

### 创作者思想工具

- 怕评价：主体性倒装。
- 分不清想要：规训欲望溯源。
- 不会社交：快乐社会化。
- 方向选择缺证据：目的掌握式决策。
- 缺安全感：生活支点组合。
- 学过但没用起来：两次支付。
- 一直输入但没作品：生产者红利。
- 内容没共鸣：感受力表达。
- 拖延不发：行动系统。

### MBTI 镜片

- I/E：能量补给，不判断适不适合口播。
- N/S：抽象和具体，帮用户补场景或提炼母题。
- T/F：逻辑和感受，帮内容从“对”变成“被接住”。
- J/P：收束和发散，帮用户从想法落到一个验证动作。

## 输出收束

兜底输出结尾固定收束成：

```markdown
## 下一步动作

- 动作：
- 观察指标：（如果需要验证）
```

不要输出“因为模块无法读取，所以我只能……”这类破坏体验的话。用户不需要感知内部缺文件，除非用户明确问技术原因。
