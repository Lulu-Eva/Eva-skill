# Eva Teaching：选择式纠偏

只在对标深度带练或用户明确要求的文稿带练中，用户已对当前观察问题给出自己的判断后读取。快速拆解、深度直出和默认文稿批改不读取本文件。

判断来源由调用者确定：对标带练使用 shared Benchmark；文稿带练使用 `04_manuscript-review_文稿审核与批改.md` 选定的文体真源。下面的证据、偏差和成立条件均来自该真源，不另建判断方法。

## 本轮反馈

1. 指出用户已经看见的部分。
2. 给出一个证据锚点：引用当前真源支持的一个具体位置、原句或可见形式，让用户可以回到材料复核；不借此展开完整报告。
3. 只选一个对后续判断影响最大的偏差。
4. 只补一个来自当前真源的成立条件，不追加第二个条件，不把相关性写成因果。
5. 说明这个偏差与成立条件如何影响当前迁移或修改判断。
6. 只给出四个真实选择：

```text
再试一次
继续看下一层
直接看 Eva 的判断
退出教学
```

不在这一轮同时指出多个错误，不顺手重写用户答案。如果用户已满足当前单元完成标准，不得为凑格式虚构偏差；直接确认判断成立，再只提供一个适合当前对话的可选出口。

## 选择后的行为

- **再试一次**：保留同一观察位置和判断问题，只给一个更具体的支架；不换题，不泄露完整答案。
- **继续看下一层**：立即推进到当前真源支持、但尚未公开答案的下一个观察点；前轮纠偏已讲出的证据、条件和判断也算已公开，不把它们再包装成待答题。不强制返工，也不把未纠正判断写成“已掌握”。没有新观察点时如实收束，不强行换题或要求补新样本。
- **直接看 Eva 的判断**：说明当前证据支持的判断、一个成立条件及适用边界，但不生成仿写稿、相似选题或未经授权的修改稿。
- **退出教学**：停止带练。用户已指定真实任务时同轮转交；未指定时停在当前结果。
- **改要求直接输出**：立即停止带练；对标任务按 `02_benchmark-deep_深度对标拆解.md` 深度直出，文稿任务按 `04_manuscript-review_文稿审核与批改.md` 批改讲解或执行已授权修改，不再要求用户先修改答案。

“再试一次”是选择，不是通关门槛。完成判定、自有材料迁移和无支架判断不得作为第五个选择混入本轮。完成当前分支后，返回调用的对标深度或文稿批改 reference 判断是否结束。
