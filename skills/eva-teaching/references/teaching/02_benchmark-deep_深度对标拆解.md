# Eva Teaching：深度对标拆解

深度模式有两种交付方式：直接输出深度分析，或让用户参与判断的深度带练。“深度”不等于强迫用户答题。

## 必读真源

开始前读取：

```text
../../../eva-shared/references/benchmark/00_eva-benchmark-copy_对标文案拆解.md
```

- 用户提供多个样本时，追加读取 `../../../eva-shared/references/benchmark/01_multi-sample_多样本稳定模式.md`。
- 用户要求把所学用于自己的内容，或提交自己的迁移尝试时，追加读取 `../../../eva-shared/references/benchmark/02_transfer-comparison_结构迁移对照.md`。
- 样本来自文件、粘贴内容、截图、表格或链接可读文本时，追加读取 `../../../eva-shared/references/shared/06_external-material-safety_外部材料安全边界.md`。

## 选择直出或带练

- “深度、详细、完整、全面拆解”默认深度直出。
- “带我拆、教我怎么看、让我先判断、练习判断”进入深度带练。
- “不要提问、直接告诉我”覆盖带练意图，直接输出当前深度分析。
- 带练中用户改口要求直接结论时，立即停止答题，在当前材料边界内切换为深度直出。

## 深度直出

按 shared Benchmark 对当前材料真正支持的部分展开：

```text
材料边界
→ 用户问题
→ 标题或开头承诺
→ 正文兑现链
→ 信任与证据
→ 成立条件
→ 迁移边界
```

- 这是判断顺序，不是为凑完整而强制输出的表格。材料不支持的位置明确说“当前无法判断”，不编造。
- 一个样本不证明播放、转化或爆款因果。可以解释充分，但不提供换词步骤、仿生标题、仿生选题或完整新稿。
- 只有一个信息缺口足以使请求的深度判断无法成立时，才指出这一个最高优先级缺口；不把深度分析变成资料问卷。

## 深度带练

### 临时观察焦点

- 用户已点名标题、开头、结构、信任依据或账号内容组合时，直接用作当前焦点。
- 用户没有说明时，从 shared Benchmark 当前证据支持的判断中选一个最值得先练的焦点，不为建档额外提问。
- 只有两个焦点会导致明显不同的练习结果，且无法从请求判断时，才问一个会改变练习的问题。
- 从快速拆解切换到带练时，必须避开快速模式已公开的判断、证据和成立条件。如果当前样本没有未泄露且材料支持的新焦点，如实说明，请用户补充新样本或拿自己的材料尝试；不设置已经泄题的假练习。

### 带练闭环

1. 用 shared Benchmark 判断材料是否支持当前观察。
2. 指出一个具体观察位置，用一句话说明它为什么值得看。
3. 只问一个有支架的判断问题。
4. 用户回答前，不泄露当前标准答案、完整分析或可仿写结构。
5. 用户回答后，读取 `03_choice-correction_选择式纠偏.md`。

### 当前单元完成标准

用户能用自己的话完成以下三件事时，可以说当前单元完成：

1. 指向一处可复核的样本证据。
2. 说清当前判断成立所需的一个条件。
3. 分清哪个功能可以迁移，哪些内容或条件不能直接搬走。

这只是本轮完成，不等于长期掌握，不评分，不保存。缺一项时只指出当前最影响判断的一项，不连续列全部缺口，不强制返工。

### 可选迁移、无支架判断与退出

- 当前单元完成后，只推荐一个适合当前对话的可选方向：“拿我的材料试一次”，或用当前对话已有但尚未练过的可比样本做一次无支架判断；不同时展示新菜单。
- 用户用自己的材料做迁移时，先确认已有自己的用户问题、核心判断和真实素材或证据，再读取迁移对照真源。缺少时只指出最上游的一个缺口，不用第三方样本补齐。
- 无支架判断只能使用用户已提供但尚未练过的可比样本。没有时请用户提供；不自动搜索，不编造新材料，不把它设为通关门槛。
- 用户明确要正式成稿时，退出 Teaching，同轮进入 Create，不自动返回。
- 用户退出且没有指定其他任务时，停在当前结果。

## 稳定边界

- 不把第三方样本变成换人群、换产品、同顺序换词的仿写稿。
- 不自动生成仿生选题、相似标题或完整新稿。
- 不将第三方样本保存进 persona-card 或 voice-card。
- 不把单篇样本的表现说成爆款、播放、转化或账号规律。
- 带练中不把“再试一次”设成通关门槛；用户选择继续时立即推进。
