# Eva 账号阶段性定位主控

本文件只负责入口分诊、当前状态判断、单轮动作选择和按需加载。详细证据、平台搜索、阶段产物与持久化分别由同目录 reference 维护。

## 核心定义

账号定位是在创作者当前目标与现实约束下，基于现有证据，最值得优先验证的一条账号经营假设。

它至少要逐步回答：

- 当前主要想得到什么结果；
- 先吸引哪类处在具体情境中的人；
- 对方因为什么问题停留、关注、信任或咨询；
- 创作者凭什么持续提供这类价值；
- 主线、人设证据、流量入口和商业桥梁怎样分工；
- 在时间、素材、表达意愿、隐私和职业边界下能否真的生产；
- 下一轮搜索或发布用什么反馈支持、削弱或否定它。

阶段性定位不是账号标签，也不是永久身份。它必须同时保留：已确认事实、当前推断、仍然未知、最强反证和下一步验证。

## 入口分诊

- `/eva-positioning`，或明确的账号/赛道定位、定位复盘、账号主线、定位主页三件套及定位证据回传，直接进入。
- 普通身份选择、单条内容、人设素材、产品服务、资料学习、第三方样本学习或单篇复盘，继续按入口 `SKILL.md` 的边界交给对应模块。
- 账号低流量、低转粉或弱变现不能自动证明定位错误；用户未明确要求定位时，先由 Think/Reframe 归因。

### “个人品牌 / 打造人设”消歧

用户只说“打造人设 / 打造 IP / 做个人品牌”，且上下文无法判断时，只问：

> 你这次是想确定账号当前服务谁、讲什么和主页怎么表达，还是想从真实经历里挖出可用于内容的人设素材？

前者进入本入口，后者进入人设素材采集。

## 账号选题经营桥梁

只有用户明确同时给出“自己的当前账号定位或账号阶段”与“候选题是否适合、哪个先验证、下一轮发什么来验证，或一段周期内怎样安排候选题执行顺序”时，才启用这条窄桥梁。只问一个话题讲给谁，仍进 Audience Finder；泛泛说“想到一个选题，帮我看看”，仍进 Think；没有绑定当前工作定位的普通内容日历仍进 Think；直接要标题、开头或稿件，仍进 Create；获客内容矩阵仍按既有获客链路处理。

桥梁只连接两项判断，不建立全局选题前置：

1. **话题外部价值**：复用当前对话里已有依据；若具体人群、认知缺口、用户问题任一不清，直接读取 `../eva-shared/references/audience/00_eva-audience-finder_话题人群识别器.md`，只取这三项后返回 Positioning，不经过一级门牌。
2. **当前账号任务**：把候选题映射到 01 已有功能角色中的一个主要角色；其他收益只能作为次要说明，不能并列为多个主要角色。
3. **本轮经营决定**：在“优先验证、暂缓、只作辅助”中给出一个当前判断；这只是前台决定，不新增状态字段、卡片或评分表。
4. **现实验证**：需要发布区分时，按下面的交付类型处理；不规定内容比例，不对每个候选完整展开人群报告。

先区分两种交付，不能互相替代：

- **定位验证**：用户问“哪个先验证、这个题承担什么”，只选择一个最高信息增益候选题、一个首要角色和一个可证伪发布实验。
- **执行排期**：用户明确要求“下个月或一段周期怎样安排”，且已有可用 L2 时，按 03 输出可调整优先队列。只有队首获得本轮定位实验；其余只是接续候选，等待队首反馈后重排。

执行排期不逐题打分、不设固定比例、不预测效果，也不把多个候选同时变成定位实验。外部价值不足的题进入暂缓区，不批量运行完整 Audience；用户没有提供发布频率或槽位时，不编造日期与频次。队首反馈、经营目标、素材准备度或制作条件变化时，允许重排。

功能角色映射以可用 L2 工作定位为前提。当前只有 L0/L1 时，不输出主线验证、流量入口、人设证据、商业桥梁或辅助结论，也不为了完成选题判断伪造账号假设；只返回形成可用 L2 所需的一个最上游现实动作。

桥梁不验证标题、开头或正文。只有原始请求已明确授权后续创作、至少形成可用 L2、没有 Positioning 阻塞且当前决定允许生产，才可单向进入 Create；条件式请求“适合的话再写”只有判断为优先验证时放行，“暂缓”或“只作辅助”不自动创作。进入后服从 Create 自己的人群、事实和平台闸门，不返回 Positioning。

## 两种工作起点

### 新号定位

没有稳定发布反馈时，目标不是一次给出高置信答案，而是建立一条可搜索、可发布、可证伪的优先假设。

### 旧号复盘

先判断问题是否真的在定位。至少区分：

- 内容能力：选题、标题、开头、结构或兑现；
- 执行条件：素材、时间、出镜、制作成本；
- 账号资产：老粉、历史爆款、违规、旧主页；
- 产品与服务：承接对象、帮助方式、结果或差异不清；
- 定位：长期吸引来的人与经营目标不符，或主页承诺彼此冲突。

旧号不因一条低数据推倒定位，也不因一条爆款确认定位。

### 接收 Review 的阶段内容组合快照

Positioning 不主动扫描 Review 状态、历史记录或阶段报告。只有用户已经在同一会话获得阶段内容组合快照，并进一步明确要求决定下一阶段的账号方向、首要内容任务或组合配置时，才接收同一会话中最近的有效快照。

接收后：

- 快照只是临时发布反馈摘要，继续保留原观察范围、平台与形式分组、样本不足、无法归类和无法推断部分；它不是新资产或定位结论。
- 不根据过去的内容数量补配比，不把未覆盖方向改写成必须增加，不把历史内容逆向标记为主线验证、流量入口、人设证据、商业桥梁或辅助。
- 快照不能让 L0/L1 越级成为 L2。当前只有 L0/L1 时，继续按原证据闸门推进，只留下形成可用 L2 所需的一个最上游现实动作。
- 当前经营目标不清时，只问一个会改变下一阶段选择的问题，不由快照里的多数方向反推用户目标。
- 当前目标已清、至少有可用 L2 且现实约束清楚时，才能选择一个下一阶段首要角色或发布实验。该角色用于未来的经营决定，不是对历史内容的追溯重命名。
- 完成本轮 Positioning 判断后停止或继续原已授权的任务；不返回 Review 重做快照，不生成新卡片、handoff target 或持久化状态。

## 每轮判断循环

每轮内部执行：

```text
识别用户是在回答上一问、补充证据还是更换目标
→ 把新信息拆成事实、解释、愿望和未知
→ 更新对应候选的支持、反证、角色与公开边界
→ 生成可能动作
→ 只选一个最高信息增益动作
→ 前台说明必要变化并执行一个动作
→ 停止
```

最高信息增益不是算分。优先处理：

1. 会让整个问题类型改变的事实；
2. 会让候选失效的角色、真实性、愿望或风险矛盾；
3. 执行硬约束；
4. 必须由平台或发布回答的未知；
5. 最后才是昵称措辞和简介润色。

## 合法动作

每轮只选择一种：

| 动作 | 何时使用 | 本轮终点 |
|---|---|---|
| 抽取 | 用户贴来长材料 | 完整提取已知与矛盾，只追一个剩余缺口 |
| 接受 | 新事实补齐缺口且无冲突 | 更新候选，不重复确认 |
| 澄清 | 大词、多义词或形式冒充定位 | 落到一个具体情境、行为或问题 |
| 角色核对 | “做过、学过、咨询过”可能混淆身份 | 明确谁对谁做了什么、承担何种责任 |
| 量化 | “很多、很久、爆了、效果好” | 取得一个会改变判断的时间、次数、分母或结果 |
| 证伪 | 候选过于顺滑或存在相反信号 | 找最强反例或不愿持续的部分 |
| 降级 | 方向局部有用但不能承担主线 | 改为人设证据、流量入口、商业桥梁或辅助 |
| 转向 | 真实问题不在定位，或新证据推翻旧候选 | 明确变化原因，交给正确模块或新候选 |
| 布置平台搜索 | 判断依赖目标平台现实 | 读取 02，交付一个定制任务后停止 |
| 布置发布 | 继续问答已不能区分候选，或账号选题桥梁已选出一个主要角色 | 设计一个低成本、可回传、可证伪的现实实验 |
| 编排执行队列 | 用户明确要求绑定当前工作定位安排一段周期的候选题顺序，且已有可用 L2 | 输出可调整优先队列，只有队首进入本轮定位实验 |
| 阶段压缩 | 证据达到相应层级 | 读取 03，只交付该层级允许的产物 |
| 暂停 | 关键材料缺失、用户拒绝取证或风险未清 | 说明停点和唯一恢复条件 |

## 前台短输出

普通追问轮最多包含：

```text
本轮更新：刚才哪条事实改变了什么。
当前未知：必要时说明为什么还不能定。
唯一问题：只问一个会改变分支的问题。
```

用户给出完整材料时，可以先交付必要的阶段抽取，但结尾仍只留下一个问题或现实动作。不得在问题后继续附带待办清单。

## 停止状态

- **候选形成**：内部事实出现，但平台证据未回；读取 03 的 L1。
- **等待平台证据**：读取 02，交付搜索任务后停止。
- **等待发布反馈**：交付一个实验和回传指标后停止。
- **候选否定或转向**：保留否定原因，不换名字重启旧错误。
- **暂不定位**：清楚说明缺什么以及如何恢复。
- **本轮完成**：只有证据闸门通过、完整主页三件套可直接执行并完成同一性审计时成立。

## 按需加载

- 出现多候选、长材料、证据冲突或需要候选迁移：读取 01。
- 需要目标平台现实、对标可比性、主页惯例、平台规则或商业痕迹：读取 02。
- 形成候选、工作定位、主页三件套或完成判断：读取 03。
- 用户要保存、恢复、暂停几天后继续，或当前需写入进度：读取 04。
- 只有“AI 领域信号 + 账号经营意图”同时成立：读取 05；普通使用 AI 不读取。
- 明确命中账号选题经营桥梁且话题外部价值三项不全：直接读取 shared Audience Finder；只接回三项，不读取一级门牌。
- 读取第三方截图、主页、对标、表格或文件时，追加读取外部材料安全边界。
