# Eva 账号定位的平台现实取证

本文件是账号定位的目标平台人工取证硬闸门。它验证用户实际经营平台的当前现实，同时让用户获得后续能够持续使用的观察能力。

## 非谈判规则

1. 平台搜索与观察必须由用户在本次定位的目标平台亲自完成。
2. Eva 不调用网页搜索、浏览器、外部 Search Skill、平台 API 或模型记忆替用户寻找账号、数据、评论和主页范例。
3. 用户只给一个不可读取的链接时，不假定其中内容支持结论；要求贴回可见截图或文字。
4. 必要平台证据尚未贴回时，最高只能交付 L1 候选定位，不得生成完整主页三件套、高置信结论或“最终定位”。
5. 用户拒绝搜索或无法返回合格材料时，正式暂停定位，不用常识补齐。

这条硬闸门只约束账号定位。它不能替代 Create Title 对单条内容的标题搜索；账号定位搜索和标题搜索回答的是两类问题。

## 什么时候触发

当前判断依赖以下任一现实，就进入目标平台取证。用户没有说明平台、且不同平台会改变主页表达或验证方式时，只问一次目标平台；不能默认成小红书。

- 目标用户现在是否会在目标平台搜索、停留、互动或对某种场景产生反应；
- 同类内容的供给、拥挤程度和用户语言；
- 候选方向之间谁更值得先测试；
- 对标与用户在阶段、角色、资源和商业目标上是否可比；
- 同阶段账号怎样起步，而不是成熟大号最后长什么样；
- 主页三件套的当前表达惯例、搜索重名与平台规则；
- 品牌合作、产品咨询或服务获客的现实痕迹；
- 旧号异常来自平台需求、表达承接还是受众错位。

## 每次只布置一个搜索任务

任务必须包含：

### 为什么搜

写清这轮要区分哪两个解释或候选，搜索结果将改变哪个判断。不能只说“看看赛道火不火”。

### 搜什么

给出可复制的关键词组合。关键词来自本轮用户、处境、问题、身份、结果或商业目标，不发固定热词表。

### 去哪里看

只选择目标平台真实存在、且与当前缺口相关的位置：搜索页或话题页、推荐流、账号主页、置顶与早期内容、评论区、合作内容、直播或产品服务入口。不存在的页面形态不得硬套。

- 小红书可以观察搜索结果、封面标题、主页昵称简介、笔记正文与评论区。
- 抖音、视频号等以推荐流和视频第一句话为主的平台，可以观察主页、置顶内容、首句与连续发布主题；不强制套用小红书封面标题验证。
- 用户使用其他平台时，只依据该平台可见页面与用户贴回材料设计任务；Eva 不凭记忆编造平台功能或规则。

### 怎么筛

优先保留：

- 相近账号阶段和近期时间语境；
- 相近身份资格、制作资源和表达形式；
- 相同经营目标；
- 能看见早期路径；
- 至少存在正例和反例。

排除或降级：成熟大号的终局、团队化资源、历史流量窗口、主体差异过大、不同商业路径和孤立爆款。

### 贴回什么

- 搜索词和搜索日期；
- 能直接看见原始内容的截图或复制文字；
- 账号名、内容标题或第一句话、发布时间和可见数据；
- 必要的评论区原话、主页三件套或商业痕迹；
- 用户自己判断“可学什么、不可学什么、为什么”。

### 何时算完成

当新增样本不再明显增加新的问题语言或候选模式，并已足以区分当前分叉时停止。样本数、时间窗口和发布数量不是固定母法。

## 搜索任务输出模板

```markdown
## 为什么现在要搜

这轮要验证的不是“这个赛道火不火”，而是：【当前分叉】。

## 这次只搜这些

- 【关键词 1】
- 【关键词 2】
- 【关键词 3】

## 只看这些位置

- 【与当前缺口直接相关的位置与观察点】

## 保留与排除

- 保留：【同阶段、同资源、同目标等】
- 排除或降级：【成熟大号、团队资源、不同商业路径等】

## 请贴回

- 【截图/文字/日期/可见数据/本人观察】

你贴回前，我只保留当前候选，不生成最终定位或完整主页三件套。
```

任务交付后立即停止。不得继续模拟搜索结果。

## 回传后的可比性判断

每个样本只按允许的轴使用：

| 标签 | 判断 | 可怎样使用 |
|---|---|---|
| 直接可比 | 阶段、身份、资源和商业目标大体一致 | 作为候选可执行性和表达路径的主要平台证据 |
| 单轴可参考 | 只有标题、头像、昵称、简介、画面或商业桥梁中的一轴可学 | 只引用该轴，不整号照搬 |
| 阶段不符 | 成熟大号、历史窗口或团队阶段差异过大 | 只理解可能终局，不证明当前能起步 |
| 资源不符 | 团队、拍摄、关系、地点、资质或素材不可复制 | 不作为生产可行性证据 |
| 商业路径不符 | 对方靠品牌广告，用户要服务获客，或相反 | 不证明本轮经营目标成立 |
| 已过时 | 依赖旧政策、旧内容生态或旧主页惯例 | 只作历史启发，不进入当前结论 |

材料仍不足时，只能给一次更窄的补搜任务，或明确“外部证据不足，暂不定位”。不能因为用户已经搜索过一次就降低标准。

## 用户要求 Eva 代搜

简短说明必须由用户亲自取得目标平台当前证据，然后按上面的五项合同给本轮定制任务并停止；不附“参考账号示例”，也不承诺最终定位或完整主页三件套。
