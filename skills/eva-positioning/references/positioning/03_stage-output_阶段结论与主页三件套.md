# Eva 账号定位阶段结论与主页三件套

不同证据状态只能生成与之相称的产物。用户想直接拿结果，不能豁免真实性、平台证据、角色和公开边界。L0—L3 只是内部权限，前台不显示编号、证据账本或内部检查表。

## 四层输出

### L0 未形成定位

适用：内部真实材料或最低限度的平台证据尚未形成，因此不能建立定位候选。

允许：

- 当前已知事实与最关键冲突；
- 真实材料已足时，最多两个“个人材料方向”；
- 每个方向值得调查的内部依据、缺少的平台现实与当前不能推导的结论；
- 一次定制搜索任务，或唯一恢复材料。

禁止：定位候选、赛道结论、目标人群承诺、功能角色、主页文案或“你的定位就是”。

### L1 候选定位

适用：内部真实材料与最低限度的合格平台证据同时存在，已经可以形成一份阶段定位候选，但仍有会改变路线的冲突或证据缺口。

允许：

- 最多两个候选及其支持和反证；
- 候选的公开边界；
- 当前不能下结论的原因；
- 一个会区分候选的内部核对、补充取证或现实动作。

禁止：把候选写成可直接执行的工作定位、分配选题功能角色、生成主页方案或确定性商业结论。

推荐格式：

```markdown
## 当前只到候选阶段

### 候选：【工作名称】
- 它面向谁的什么处境：
- 当前支持证据：
- 当前反证或约束：
- 当前验证状态：
- 公开边界：
- 还不能下结论的原因：

### 下一步只做这一件事
- 【一个问题或平台搜索任务】
```

### L2 工作定位

适用：内部事实和平台证据已经能支持一份当前可执行的工作定位，主要意愿、产能或经营冲突不会阻止起跑。它是快速定位的合法完成结果，不以重复发布反馈或主页三件套为前置。

允许：

- 当前服务的人与具体处境；
- 账号持续提供的价值变化；
- 用户的表达资格与独特位置；
- 当前内容主线、流量入口、人设证据和商业桥梁；
- 当前明确不做什么；
- 仍待验证什么；
- 一轮现实发布实验。

可被后续反馈改写，但前台不需要用“尚未完成”否定它的可执行性。用户明确要主页时，可按后文交付“当前可用主页方案 v0”。

### L3 深度阶段定位

只有以下关键闸门闭合时生成：

- 当前经营目标与账号阶段清楚；
- 主线候选有内部事实支持；
- 用户已经提供必要平台证据；
- 角色、隐私、公开声明和生产条件清楚；
- 内容主线与必要的人设证据、流量入口、商业桥梁或辅助已完成当前阶段的必要分工；
- 若关键分叉依赖发布或业务反馈，相应证据已经形成；
- 仍未知部分已经标明，不会改变当前阶段的主路线。

L3 的完成条件是影响当前路线的关键证据、冲突和边界已闭合，不以主页三件套为必选产物。用户明确要主页时，再交付成熟主页方案。

## 快速定位默认输出

L2 成立后，快速模式默认交付：

```markdown
## 当前阶段先这样跑

- 先让谁因为什么问题认识你：
- 你当前准备让公众先看见哪一部分：
- 这部分为什么由你来讲：
- 这一阶段优先讲什么：
- 暂时不承担什么：
- 当前证据支持到哪里：
- 只验证一个什么判断：
```

这份产物是当前可执行定位，不需要附上主页三件套或把内部层级告诉用户。

## 主页三件套

主页三件套固定指：头像、昵称、简介。它是用户明确需要时才生成的公开表达层，不是定位起点或完成门槛。

- L2 可交付“当前可用主页方案 v0”，并明确会随后续证据修订。
- L3 可交付成熟主页方案。
- 用户只要修改昵称、简介或头像其中一项时，只处理该项，同时核对它与另外两项是否一致；不强制整套重做。

### 头像

头像压缩第一眼的身份感、关系距离、气质与识别性。输出必须明确：

- 保留或更换；
- 真人、侧脸、背影、环境人像、插画、Logo 或其他可执行形态；
- 主体、裁切、背景与需要避免的误读；
- 若需补拍，给出可执行拍摄规格。

真人头像不是绝对规则。机构号、匿名职业号、艺术账号和已有强识别资产可以有不同选择；当前平台惯例由用户亲自搜索。

### 昵称

昵称压缩可记忆主体和一个最重要的相关信号。输出只给一个主定稿，并检查：

- 第一次看到能否读懂；
- 过一会能否复述并找回；
- 不听私人解释也成立；
- 与头像、简介和真实内容是同一个人；
- 不制造错误财富、年龄、专业或内容预期；
- 用户愿意被这样称呼；
- 用户已核对重名、歧义和平台规则。

仍有两个会改变路线的候选时，不算完成；先安排辨别任务。

### 简介

简介按功能组织，不机械限制三行：

- 识别与可信：为什么是用户；
- 关注预期：账号会稳定提供什么；
- 关系与方向：这些内容如何属于同一个人、同一阶段，或真实服务边界与行动关系是什么。

不同目标允许不同重点：涨粉强调正确用户自我代入；接广强调真实人群、场景和内容能力；获客强调合法背书、可承接问题与服务边界；过程型新号强调正在进行的真实计划，不冒充结果。

价格、名额、联系方式、咨询口令和 CTA 不是定位必选项；没有真实入口或用户未授权时不得生成。

### 三项同一性审计

组装后检查：

1. 三项是否在讲同一个人、同一阶段；
2. 是否共同吸引当前目标用户；
3. 头像关系距离、昵称信号和简介承诺是否冲突；
4. 简介承诺能否被近期内容、置顶、服务或经历证明；
5. 是否有一句换到任何同类身上都成立；
6. 是否加入与用户收益无关的高势能词；
7. 是否强迫公开只适合后台的经历；
8. 用户是否愿意被这套主页代表；
9. 依赖目标平台现实的判断是否已有用户回传证据。

## 深度定位输出

L3 默认先交付阶段定位与证据边界。只有用户明确要主页方案时，才在中间加入“当前主页三件套”；用户只要其中一项时，只渲染该项。

```markdown
## 当前阶段定位
- 一句话：
- 当前目标用户与处境：
- 主线：
- 辅助与明确不做：
- 素材来源与现实形式：
- 人设证据与公开边界：
- 商业桥梁：

## 当前主页三件套（按需）

### 头像
- 结论：保留 / 更换
- 可执行规格：
- 选择理由：
- 避免：

### 昵称
- 定稿：
- 选择理由：

### 简介
- 第一展示单元：
- 第二展示单元：
- 第三展示单元：

### 三项共同传递的认识

## 证据与边界
- 内部事实：
- 用户回传的平台证据：
- 发布或业务证据：
- 主动舍弃：
- 当前仍未知：
- 复盘触发条件：
```

主页部分不在用户要求内时整段省略。展示单元不等于必须三行；当前字数、行数和平台展示由用户当期提供的平台现实确认。

## 发布验证

发布不是执行已经确定的定位，而是在制造定位证据。每轮只验证一个假设：

- 预期吸引谁、触发什么反应；
- 哪些变量保持不变；
- 什么信号支持、削弱或无法判断；
- 记录触达、消费、主页承接、人群、经营与制作反馈；
- 何时带材料回来复访。

不设固定发布条数、点赞率、转粉率或粉丝门槛。第一批有效样本必须保留用户自己的选题判断、事实选择和核心表达，不能让 AI 全程代写后再把结果当成用户能力证据。

## 账号选题经营桥梁输出

这份输出只回答候选题在当前账号阶段承担什么任务，不会把 L0/L1 越级成 L2/L3，也不替代标题、开头或正文闸门。只有当前已有可用 L2 工作定位时才渲染下方模板；只有 L0/L1 时不分配功能角色，只给一个形成 L2 所需的上游现实动作。前台只交付：

```markdown
## 本轮账号选题判断
- 预期吸引谁：具体人群
- 话题外部价值依据：认知缺口 / 用户问题
- 当前首要功能角色：主线验证（沿用“主线”角色）/ 人设证据 / 流量入口 / 商业桥梁 / 辅助（只选一个）
- 当前决定：优先验证 / 暂缓 / 只作辅助
- 本题不能证明：
- 判断依据与最强反证：

## 本轮唯一现实动作：只做这一项发布实验
- 唯一假设：
- 保持不变：
- 支持 / 削弱 / 无法判断的信号：
- 需要回传的材料：
```

定位验证每轮只选一个最高信息增益候选题和一个发布实验；不输出选题打分表、固定内容比例或多个并列主要角色。

用户明确要求绑定当前工作定位安排月度或周期执行顺序、已有可用 L2 且多个候选题的外部价值依据足够时，改用下方模板。它不是评分表或稳定内容配比；只有“现在执行”拥有本轮定位实验：

```markdown
## 当前周期可调整优先队列

### 现在执行
- 候选题：
- 首要角色：
- 为什么现在：
- 本轮唯一定位实验：

### 接续候选
1. 候选题：
   - 首要角色：
   - 前移条件：

### 暂缓
- 候选题：
- 缺失依据或最强反证：
- 恢复条件：

### 重排触发
- 队首发布反馈：
- 目标、素材或制作条件变化：
```

用户没有给出周期槽位时，不编造日期或发布频次；接续候选不各自携带发布实验。队列只在当前会话使用，不新增状态或保存对象。

若原始请求已经授权写稿，后台仍完成本节的完整判断。当前至少达到可用 L2、没有 Positioning 阻塞、决定为“优先验证”且用户没有要求详细解释时，前台不展示完整桥梁模板，只保留：

```text
适合，因为【人群问题与当前定位或首要角色的具体对应关系】。
发布后只观察：【一个能支持或削弱该定位假设的人群或反馈信号】。
```

随后单向进入 Create，由 Create 继续自己的闸门，不返回 Positioning；上游已经说明适配理由时，不再附加导航说明句。L0/L1、证据冲突、暂缓、不适合，或条件式请求中只能“只作辅助”时，不使用轻量放行模板：只展示必要结论、一个关键依据或反证和一个解除或替代动作，并停止。用户明确要求详细解释时可以展示完整判断；判断放行且仍授权创作时，再进入 Create。

## 复访触发

- 实际吸引的人与目标明显不同；
- 连续系列长出更清楚的问题或关键词；
- 经营目标从涨粉转为接广、获客、产品或长期影响力；
- 旧标签不再真实或用户不再愿意公开；
- 主页承诺被反复误读；
- 新内部事实、平台证据或发布反馈足以推翻旧优先级；
- 平台主页规则发生变化。

复访先归因，不因一条低数据重做三件套，也不因一条爆款永久固化定位。
