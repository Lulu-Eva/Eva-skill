# Eva-skill 短视频节拍与心智推进

本文件是 Opening、Script 与短视频 Preflight 共用的唯一节拍语义真源。它只处理短视频的心智推进，不适用于 Article、Think、Lens、Audience 或 Positioning。

## 核心定义

```text
节拍：围绕当前主问题完成的一次最小有效心智推进。
支撑：帮助当前节拍成立的场景、证据、解释、动作、边界、停顿或转场。
节拍链：从用户原有理解走到标题或第一句话承诺终点的必要推进顺序。
内部表示：起点理解 → 推进材料或动作 → 新理解位置
```

判断一次推进是否成立，只看用户对当前主问题的理解有没有发生必要变化，不按句数、段数或字数计算。

```text
用户原有理解
→ 最少必要节拍链
→ 本稿允许抵达的新理解
```

- 第一拍从用户原有理解出发，相邻节拍能够连续承接。
- 认知终点不得超过标题或第一句话承诺，也不得超过现有事实、经历与证据。
- “最少必要”指不保留多余理解变化，不等于越短越好；承担不同功能的真实阶段、轮次与过程必须保留。

## 四类失效

- **停拍**：文字增加，但围绕当前主问题的理解没有移动。
- **复拍**：已经完成的理解变化被换词、换比喻或换情绪重复。
- **跳拍**：从起点跳到新结论，缺少必要前提、因果、解释或证据。
- **挤拍**：一次塞入多个彼此独立的理解变化，用户无法完成当前变化。

## 动态期待覆盖

- 一项用户期待可以由一拍回答，也可以由多拍共同回答；一拍可以回应相邻的多项期待。
- 本稿暂不回答的期待必须明确舍弃，不能为了覆盖完整而扩大承诺。
- “用户最后想带走什么”用于确定收束方向，但不机械等于最后一拍，也不自动等于 CTA。

## 必要支撑与观看边界

- 场景、证据、解释、动作、反例、边界、停顿和转场只要帮助当前节拍成立，就不是水分。
- 真实停顿、情绪停留、口播呼吸和受 voice-card 或用户原稿保护的必要重复可以保留；纯同义改写仍属于复拍。
- 已有材料含具体落点却未用于当前推进时，才判断当前节拍缺少可感知支撑；材料没有时不得编造。
- 理解门槛、代入断点、情绪掉线、节奏同质、转场不连续、口播负担和用户文风继续独立判断，不能被节拍标签取代。

## 固定边界与优先级

- 不规定固定拍数、每段一拍、每句一拍或每分钟拍数，也不建立节拍评分、密度或 KPI。
- 一句话可以完成一拍，多句话也可以共同完成一拍；30 秒与 90 秒可以共享必要理解步骤，但支撑深度和有效阶段可以不同。
- 节拍只组织已经成立的内容，不新增事实、立场、因果、第一人称经历或隐私边界。
- 优先级固定为：事实与安全、Brief、平台规则、标题或第一句话承诺、原意与事实颗粒度、正文兑现、voice-card 与口播自然 > 节拍清晰度。
- 节拍不能覆盖 Audience、方法动作颗粒度、动态时长、低置信度或用户明确要求，也不能把短视频改成观点机关枪。
