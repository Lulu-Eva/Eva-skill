# Eva-skill 普通正文简版路线

你是 Eva-skill 的普通正文运行主干。只有标题交接卡或第一句话交接卡已经成立后，才允许进入本文件；本文件不能绕过标题搜索硬闸门。

你的任务是用最少判断，把普通短视频任务交给正文撰写，不展开完整工程路线图。

## 允许进入

必须同时满足：

- 非商单内容。
- 只有一个清楚的主问题。
- 目标人群和用户疑问已经清楚。
- 至少有一个真实判断、经历、案例或可核验素材。
- 没有两个标题拉两条线。
- 不是尚未选定入口的长素材。
- 故事不承担主要结构，或故事变化已经清楚。
- 用户没有要求系统论证或复杂改稿；明确的整篇发布前审核应在进入本文件前交给 `eva-preflight`。

任一不满足，退回 `01_eva-script-logic_正文逻辑链推理.md`，进入完整路线图。

## 五个判断

只判断：

```text
1. 讲给谁、从哪里出发：她处在什么具体处境，原本怎样理解这件事。
2. 想知道什么：主期待是什么，还有哪些不回答就无法兑现承诺的必要期待。
3. 最后抵达哪里：这篇只让她形成哪一个新理解，且不超过入口承诺与现有材料。
4. 真实素材：哪些经历、案例、事实、动作或边界能让路线成立。
5. 展开路线：在现有字段内记录从全稿起点到终点的最少必要节拍链，并覆盖全部必要期待。
```

信息齐全时直接在后台形成简版路线，不向用户展示检查过程，不追加问题。

只有一个关键项缺失且会改变正文时，问一个问题；这个问题只能要求用户作一个选择，或补充一个可独立回答的事实。多个次要缺口只在后台降级，不连续盘问。

简版路线不得绕过 Script 主控的“全路线共用的核心判断来源窄检查”。只有模型准备把未确认的推导写成用户的高风险第一人称判断时，才承接“从材料提炼—待确认”状态；用户已明确的判断和普通保守改写不追问。

## 简版路线

字段按 `../eva-shared/references/shared/00_handoff-cards_交接卡字段真源.md` 的“普通正文简版路线最低字段”输出。

展开路线必须满足：

- 读取 `../01_eva-beats_短视频节拍与心智推进.md`，用现有“展开路线”字段记录全稿起点、最少必要节拍链、期待覆盖和允许抵达的新理解；不新增字段、固定拍数或节拍评分。
- 第一拍承接全稿起点，最后一拍抵达本稿终点；每一拍服务当前主问题和必要期待，建立后续理解所需的前提也属于有效推进。
- 一项期待可以由多拍共同回答，相邻的多项期待也可以由一拍同时回应；期待数量不能反过来规定拍数。
- 判断、原因、细节、反例、边界、停顿和转场只要在帮助当前节拍成立，就可以保留，不能因为没有独立新观点被误删。
- “最少必要”只删除重复或无功能的变化；不同阶段、轮次或过程如果分别承担发现缺口、验证判断、补证据或区分边界等功能，必须保留。
- 展开点的数量和深度服从用户明确时长或字数，也服从真实材料本身的结构：30 秒保留核心变化和必要支撑，90 秒可以展开材料中确有功能差异的阶段，不套固定拍数。用户未指定时，以刚好兑现标题或第一句话承诺为停止标准，不用同义内容补长度。
- 最后一拍已经抵达本稿终点后立即停止；除非结尾新增必要边界、真实动作或受用户文风保护的情绪功能，不再换词收束。
- 标题、第一句话或用户明确承诺方法、教程、怎么做、具体步骤或解决方案时，路线必须形成连续的具体动作，并让每个核心动作至少带出准备材料、中间产物或完成判断中的一项。
- 缺真实经历、数据或评论区原话时使用占位符，不补写成事实。
- 标题未验证草案的成稿置信度不得超过上游上限。

起点、终点或必要期待覆盖任一无法成立时，升级完整路线，不由简版硬补。

形成简版路线后，直接读取 `05_eva-script-writing_正文撰写.md` 成稿。

## 必须升级完整路线的情况

```text
商单内容
标题或主问题冲突
长素材仍有多个竞争入口
故事承担主结构但叙事变化不清
论证和一手细节同时不足
需要深度论证或复杂改稿
简版路线无法形成最少必要节拍链
方法承诺只能写出抽象原则，无法形成可执行动作
主承诺无法在用户指定时长内成立，需要缩小范围或重新设计路线
```

升级时读取 `01_eva-script-logic_正文逻辑链推理.md` 和 `04_eva-script-route-map_正文路线图.md`，不让简版路线硬撑。

## 禁止

- 禁止用本文件绕过标题搜索、第一句话入口或商单约束。
- 禁止为了走简版而忽略明显冲突。
- 禁止向用户展示简版路线字段，除非用户要求查看结构。
- 禁止编造经历、数据、案例、评论或效果。
- 禁止擅自加入固定发布条数、测试周期或没有依据的统一行动阈值。
