# Eva-skill

Eva-skill 是一个面向创作者的思考陪练与思维流爆款短视频工具箱。

当前版本：`1.1.3`

它不只是写稿工具，而是帮助创作者把混乱想法放回正确位置：

```text
私人感受 -> 公共表达 -> 长期资产
```

适用于小红书、抖音、视频号等口播短视频创作，也适合在创作者脑子乱、方向卡住、表达欲很多但说不清时，先做思考整理。

Eva 的互动会更像一个懂内容的创作者陪练：先接住你的混乱，再帮你归位，最后推进一个现实动作。它会保护创作者自己的表达，不会把学员稿件改成统一口吻。

新版加入了“模块主权”机制：选题、标题、文案、表现、复盘等主模块拥有自己的输入门槛、停止条件和输出格式；思想镜片、MBTI Lens、创作者思想工具、语气层只做辅助校准，不抢主流程。

`1.1.1` 加入了短视频“标题锚点”机制：当用户决定创作短视频时，Eva 会先确认封面标题、正文标题和数据参考，再拆关键词、用户疑问和发散入口；如果缺少标题数据参考，后续内容会标注为低/中置信度草案。

`1.1.2` 补充了 think 到短视频的验证桥：即便用户先在思考助理里聊出很妙的点子，Eva 也会先给 3-5 个可搜索的标题方向和验证关键词，建议用户看数据后再正式写稿。

`1.1.3` 升级标题模块为“标题锚点与用户疑问验证器”，并新增点子卡与素材回捞机制：好点子可以沉淀为带关键词的点子卡，未来写稿缺真实案例、自身思考或人设钩子时，可在用户授权后回捞使用。

## 核心能力

Eva-skill 覆盖创作者思考、问题归位、短视频生产与发布复盘，并内置创作者思想工具库、思想镜片、MBTI Lens、沉淀机制、兜底机制和互动语气层：

- 思考助理：整理表达欲、拆概念、发散内容方向、校准长期路径。
- 创作者思想工具库：自动识别主体性、规训欲望、快乐社会化、目的掌握式决策、生活支点、生产者红利、感受力表达和行动系统等底层卡点。
- 思想镜片：用维特根斯坦、杜威、温尼科特、戈夫曼、麦克卢汉、阿德勒、哈耶克、纳瓦尔等思想镜片辅助判断。
- MBTI Lens / MBTI 镜片：把 MBTI 当作低置信度观察入口，辅助校准创作能量、信息密度、情绪/逻辑配比和收束方式，不做人格测评。
- 表象问题归位：把限流、垂直、频率、为什么不涨粉等碎问题放回本质层。
- 爆款选题：从已验证需求、人群处境和爆款结构里生成可拍选题。
- 爆款拆解与网感训练：拆标题、封面、正文结构、爆点来源和可迁移动作。
- 标题封面点击率：作为标题锚点与用户疑问验证器，判断想法能否标题化、标题是否有数据验证、正文能否兑现承诺，并生成和诊断双标题、关键词拆解、用户疑问、封面画面。
- 思维流口播文案：根据选题和标题写出 800-1200 字口播稿。
- 口播情绪节奏：把稿子转成停顿、重音、表情和拍摄节奏。
- 发布复盘诊断：根据内容和数据定位最大瓶颈，并给下一版修改动作。
- 沉淀机制：当用户明确要求保存、归档、记下来、下次接着时，把思考、点子、内容或复盘整理成可回捞卡片。
- 兜底机制：当安装环境缺少参考模块时，使用简版流程继续服务，不让用户卡在工具调用失败上。
- 互动语气节奏：让 Eva 的回复更像陪练，而不是报告；同时保护用户自己的稿件风格。

## 核心判断模型

Eva-skill 的共同底层是“表达公理 + 归位漏斗”。

每次处理前，先判断问题属于哪一层：

- 概念层：词说不清、抽象词太多。
- 表达层：有感受、有经历、有观点，但不知道为什么想说。
- 用户层：不知道用户为什么会听，标题疑问不清。
- 素材层：缺真实经历、案例、数据、评论或对标。
- 链路层：选题、标题、开头、正文、表现、复盘之间错位。
- 证据层：方向、平台、数据判断缺证据。
- 行动层：一直想但不发，反复求判断替代行动。

核心规则：

- 私人感受不能直接成为内容，必须翻译成公共处境。
- 用户不是为表达欲停留，而是为“我被说中了”停留。
- 标题是承诺，正文是兑现。
- 真实素材是表达边界，不能编造经历、数据、评论区原话或对标来源。
- 单条内容是输出，母题才是资产。
- 平台反馈不是审判，而是假设验证。
- 上游错位不能靠下游补救。
- 用户的卡点常常不只是内容技巧，也可能是主体性、规训欲望、社会化、决策、支点、生产者意识、感受力或行动系统的问题。

## 安装

```bash
npx skills add Lulu-Eva/Eva-skill -g -y
```

## 使用

安装后，在支持 skills 的 Claude Code / Agent 环境里使用：

```text
/eva
/eva-think
/eva-lenses
/eva-mbti
/eva-reframe
/eva-shortvideo
/eva-topic
/eva-deconstruct
/eva-title-cover
/eva-script
/eva-performance
/eva-review
/eva-sediment
```

如果不知道该用哪个入口，直接使用：

```text
/eva
```
