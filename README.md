# Eva-skill

Eva-skill 是一个面向创作者的思考陪练与表达工具箱。

当前版本：`1.7.0`

v1.7.0 是当前稳定版本。

核心链路：

```text
想法 -> 人群 -> 标题/第一句话 -> 内容创作 -> 表达资产
```

Eva Learn 是一条主动触发的学习方法链路：

```text
提问式学习/探究问题 -> 主题式阅读/资料带读 -> 理解检查 -> 判断版本 -> 思想种子卡 -> Eva 内容链路
```

它不急着帮你写稿，而是先判断：你的想法有没有对应的人群；如果是商单内容，先拆品牌 Brief、必提禁忌、卖点池和表达风险，生成商单约束卡，再进入标题/第一句话链路；只有标题交接卡或第一句话交接卡成立后，才携带商单约束进入脚本链路。如果走小红书/有标题链路，标题不是现场生成，而是先拆爆款标题搜索方案，让用户去搜候选标题，再判断能不能一字不改使用或结构迁移；如果只想优化开头，就进入开头针对性优化，只处理第一句话、主题承接和继续看的理由；如果走抖音/视频号等无标题链路，第一句话要承担标题功能。进入完整内容创作后，Eva 不会直接成稿，而是先做正文逻辑链主控，必要时处理长素材和商单约束，最后必须经过正文路线图，再进入正文撰写。

如果你想专门学习、阅读或做主题研究，需要主动说：

```text
eva-learn
```

Eva Learn 不会因为你提到“学习、阅读、研究”就自动启动。它会先通过提问式学习把真实问题问清楚，再用主题式阅读围绕一本书、一篇材料、一个课程或多本书设计阅读任务、理解检查和阶段性判断，最后沉淀成思想种子卡。思想种子卡不是标题交接卡，也不是正文任务卡；如果要变成内容，仍然要回到 Eva 的人群、标题/第一句话和正文链路。

如果标题没有任何验证，Eva 会明确提醒你先搜候选标题、验证点击机制，不会默认进入创作层。除非你明确说“我知道没验证，先低置信度试结构”，它才会帮你输出带占位符的结构草案。

一句话说：

> 标题本身就是选题。

## 核心能力

- `/eva-think`：思考助理。适合脑子乱、表达欲很多但说不清、想拆概念、想判断一个点子值不值得继续。
- `/eva-reframe`：表象问题归位。适合限流、垂直、频率、为什么不涨粉、是不是方向错了这类容易问偏的问题。
- `/eva-audience-finder`：话题人群识别器。适合看到一个话题、热词、标题或现象，但不知道它到底戳中了谁。
- `/eva-benchmark-copy`：对标文案拆解。拆一篇对标内容的标题、用户疑问、正文结构和可迁移动作。
- `/eva-brief`：商单 Brief 需求拆解。先拆产品、必提信息、禁止信息、交付要求、卖点池和表达风险，再筛出适合学员表达资产承接的 2-3 个主讲卖点，输出可交给标题/第一句话链路的商单约束卡；不把 Brief 约束当作标题或正文入口，也不直接写完整商单稿。
- `/eva-ai-check`：表达真实性审查。不判断文本是不是 AI 写的，而是看它有没有具体意思、个人立场、身体感和内容推进；可选单点审查或全文体检，明确授权才改写。
- `/eva-memory`：点子卡沉淀与回溯。用户明确说“沉淀、保存、记下来、回捞点子卡”时，把可复用素材整理成点子卡，并在后续创作中回捞。
- `/eva-persona-memory`：人设记忆采集。不是账号定位，也不是人设包装，而是用多轮漏斗挖掘真实经历、选择代价、生活风格和表达资格，沉淀成可复用素材。
- `/eva-user-voice`：用户表达文风提取。适合提炼自己的文风、语气节奏、断句方式和表达边界，生成 `voice-card`，之后写稿时优先保护用户自己的声音。
- `/eva-shortvideo`：短视频创作主入口。只做短视频生产调度，先判断有标题链路还是无标题链路。
- `/eva-title`：标题即选题。核心不是替用户生成标题，而是输出爆款标题搜索方案、判断用户贴回的候选标题，并在标题承诺、验证线索和内容兑现都成立后输出内容任务交接卡；正文标题补强时，先找可一字不改使用的爆款正文标题，找不到才做结构迁移。
- `/eva-script`：思维流爆款内容创作入口。标题锚点成立后，先做正文逻辑链主控，判断是否需要长素材消化或商单约束检查；任何完整稿、改稿或低置信度草案进入正文撰写前，都必须先过正文路线图。开头针对性优化是轻量分支：有标题时承接标题疑问，无标题时让第一句话承担标题功能；如果用户只想优化开头，则只处理第一句话和前三句承接，不默认扩展成完整稿。
- `/eva-learn`：提问式学习与主题式阅读。只能用户主动触发，用于学习项目建档、资料存档、提问式学习、主题式阅读、理解检查、判断版本和思想种子卡；不直接代读代学，不直接写完整内容稿。

如果不知道该从哪里开始，直接输入：

```text
/eva
```

## v1.7.0 更新

v1.7.0 新增 Eva Learn，让 Eva-skill 不只处理“从想法到表达资产”，也能处理“从输入到想法”。

这次升级主要做了四件事：

- 新增 `/eva-learn` 主入口，支持提问式学习、主题式阅读、单材料带读、理解检查、判断版本和思想种子卡。
- 新增学习项目与资料存档机制：长期主题可以建立 `eva-learn/{主题名}/`，保存阅读进度、资料索引、原始资料、理解检查和思想种子卡，方便下次续学。
- 保持 Eva Learn 主动触发：主入口只提示“如果你想专门学习、阅读或做主题研究，请对我说 eva-learn”，不因为普通学习、阅读、研究词汇自动切走原有表达链路。
- 明确思想种子卡的下游边界：它不是标题交接卡、第一句话交接卡或正文任务卡；要进入内容生产，仍需经过人群/用户疑问判断，再进入标题或第一句话入口。

一句话说，v1.7.0 让 Eva-skill 有了提问式学习和主题式阅读入口，但不把它变成代学、代读或绕过创作链路的写稿工具。

## v1.6.1 更新

v1.6.1 是一次轻量化维护版，不新增省略流程的入口，也不降低反代写强度。

这次升级主要做了三件事：

- 新增 `references/shared/`，把标题/第一句话交接卡、商单约束卡/商单内容任务卡、资产状态和低置信度授权抽成共享真源。
- 压缩 `/eva-title`、`/eva-script`、`02a`、`02a3` 和 `02b` 里的重复字段表，减少热路径读取成本。
- 保留所有硬闸门：商单先拆 Brief，标题/第一句话交接成立后才进正文，完整稿必须先过正文路线图，低置信度必须明确授权且不能当终稿发布。

## v1.6 更新

v1.6 加入了商单 Brief 需求拆解，并把标题链路和正文逻辑链拆得更清楚。

这次升级的重点是把商单内容放回正确的前置判断：先拆清品牌硬要求、必提禁忌、卖点池、表达风险和学员真实素材匹配，生成商单约束卡，再进入标题/第一句话链路。只有标题交接卡或第一句话交接卡成立后，才携带商单约束进入 `/eva-script`，避免把品牌需求直接写成硬广稿。

这次升级主要做了四件事：

- 新增 `/eva-brief`，支持品牌 Brief、商单需求、合作口径、已有商单稿检查和同产品爆款样本迁移。
- 主入口新增商单优先路由：遇到品牌 Brief 或商单需求，先输出商单约束卡，不直接成稿。
- 拆分 `/eva-title`：先输出爆款标题搜索方案，等用户贴回候选标题后，再判断一字不改、借结构或放弃；商单标题也走同样的搜索和候选判断，不现场生成。
- 拆分 `/eva-script` 的正文逻辑链：`02a` 只做主控调度，`02a1` 处理长素材，`02a2` 检查商单约束，`02a3` 是进入正文撰写前的必经正文路线图。
- 版本号统一升级为 `1.6`，并保留此前已验证的标题验证、正文逻辑链和文风保护规则。

一句话说，v1.6 让 Eva-skill 能先看懂商单要求，先让用户找到可参考的爆款标题，再按正文路线图生产内容。

## 运行原则

- 主入口只做轻量归位，不展示复杂菜单。
- 每次只进入一个主模块，不同时给多条路线。
- 信息不足时只问一个问题。
- 不编造经历、数据、评论区原话或对标来源。
- 商单内容先拆 Brief，再进入标题/第一句话链路；没有商单约束卡，不直接写完整商单稿。只有标题交接卡或第一句话交接卡成立后，商单约束卡才可以随同内容交接卡进入脚本链路。
- 好点子不直接成稿，先变成爆款标题搜索方向，让用户找回候选爆款标题，再判断一字不改、借结构或放弃。
- 标题没有任何验证时，不直接写完整内容稿；先搜候选标题并验证点击机制，或由用户明确授权低置信度试结构。
- 正文标题补强不替代封面标题验证。封面标题必须继续找爆款标题和验证数据；正文标题先找现成爆款标题，能直接用就一字不改，不能直接用才迁移结构。
- 进入内容创作后，不直接跳到完整稿；先静默检查人群、表达资产和正文逻辑链条件，必要时处理长素材和商单约束，最后必须过正文路线图，只暴露一个最高优先级阻塞点。
- 开头针对性优化不替代标题验证。有标题时承接标题疑问；无标题时第一句话承担标题功能；只优化开头时不默认扩展成完整稿。
- 用户真实素材、点子卡、人设记忆和用户表达文风只保存在运行项目的 `eva-memory/`，不要提交到 GitHub。
- Eva Learn 的学习进度和资料存档只保存在运行项目的 `eva-learn/` 或用户指定目录，不要提交到 GitHub。
- 如果当前目录是 Eva-Skill 仓库本体或安装后的 `skills/eva/`，Eva Learn 不在其中创建学习项目，改用用户指定目录或 `~/Documents/eva-learn/`。
- Eva Learn 只能用户主动触发；普通书摘、课程材料或“想深入”不自动进入学习模式。
- 思想种子卡不能直接完整成稿；先经过人群/用户疑问判断，再进入标题或第一句话入口。
- 互动语气只作用于 Eva 和用户的对话，不覆盖用户自己的稿件风格。
- 如果用户没有表达文风卡，Eva 不默认把稿子写成璐璐腔；如果用户想“以后按我的语气写”，先用 `/eva-user-voice` 生成 `voice-card`。
