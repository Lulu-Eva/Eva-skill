# Eva-skill

Eva-skill 是一个面向创作者的思考陪练与表达工具箱。

当前版本：`1.5`

v1.5 是一次内容创作链路升级：继续沿用瘦身结构，但把 `/eva-script` 拆成“正文递进架构”和“正文撰写”两个内部阶段，并为抖音/无标题/专门优化开头场景增加“第一句话交接卡”。Eva 会先判断标题或第一句话能不能制造疑问，再判断正文有没有递进和真实细节，最后才进入成稿。用户声纹采集也会继续保护用户自己的语气节奏，避免所有稿子都滑向同一种口吻。

核心链路：

```text
想法 -> 人群 -> 标题/第一句话 -> 内容创作 -> 表达资产
```

它不急着帮你写稿，而是先判断：你的想法有没有对应的人群；如果走小红书/有标题链路，标题有没有被用户点击和平台数据验证，内容能不能兑现标题制造的疑问；如果走抖音/无标题链路，或你只想专门优化开头，就进入思维流爆款内容创作的无标题分支，让第一句话承担标题功能。进入内容创作后，Eva 不会直接成稿，而是先做正文递进架构，再进入正文撰写。

如果标题没有任何验证，Eva 会明确提醒你先验证标题，不会默认进入创作层。除非你明确说“我知道没验证，先低置信度写一版”，它才会帮你写试结构的草案。

一句话说：

> 标题本身就是选题。

## 核心能力

- `/eva-think`：思考助理。适合脑子乱、表达欲很多但说不清、想拆概念、想判断一个点子值不值得继续。
- `/eva-reframe`：表象问题归位。适合限流、垂直、频率、为什么不涨粉、是不是方向错了这类容易问偏的问题。
- `/eva-audience-finder`：话题人群识别器。适合看到一个话题、热词、标题或现象，但不知道它到底戳中了谁。
- `/eva-benchmark-copy`：对标文案拆解。拆一篇对标内容的标题、用户疑问、正文结构和可迁移动作。
- `/eva-ai-check`：表达真实性审查。不判断文本是不是 AI 写的，而是看它有没有具体意思、个人立场、身体感和内容推进；可选单点审查或全文体检，明确授权才改写。
- `点子卡沉淀与回溯`：用户明确说“沉淀、保存、记下来、回捞点子卡”时，把可复用素材整理成点子卡，并在后续创作中回捞。
- `人设记忆采集`：不是账号定位，也不是人设包装，而是用多轮漏斗挖掘真实经历、选择代价、生活风格和表达资格，沉淀成可复用素材。
- `/eva-user-voice`：用户声纹采集。适合提炼自己的文风、语气节奏、断句方式和表达边界，生成 `voice-card`，之后写稿时优先保护用户自己的声音。
- `/eva-shortvideo`：短视频创作主入口。只做短视频生产调度，先判断有标题链路还是无标题链路。
- `/eva-title`：标题即选题。先拆标题关键词、用户疑问、数据验证和内容任务交接卡，再决定能不能写。
- `/eva-script`：思维流爆款内容创作入口。标题锚点成立后，先做正文递进架构，判断主问题、展开关系、论证和一手细节是否足够；架构成立后再进入正文撰写。没有小红书式双标题时，使用无标题/抖音五步分支，让第一句话承担标题功能；如果用户只想优化开头，则只处理第一句话和前三步，不默认扩展成完整稿。

如果不知道该从哪里开始，直接输入：

```text
/eva
```

## 运行原则

- 主入口只做轻量归位，不展示复杂菜单。
- 每次只进入一个主模块，不同时给多条路线。
- 信息不足时只问一个问题。
- 不编造经历、数据、评论区原话或对标来源。
- 好点子不直接成稿，先变成可搜索、可验证的标题方向。
- 标题没有任何验证时，不直接写完整内容稿；先验证标题，或由用户明确授权低置信度试写。
- 进入内容创作后，不直接跳到完整稿；先静默检查人群、表达资产和正文递进条件，只暴露一个最高优先级阻塞点，避免连续跳多个子模块。
- 抖音/无标题内容不硬套小红书标题闸门，但第一句话必须承担标题功能，前三步必须让用户愿意继续看。
- 用户真实素材、点子卡、人设记忆和用户声纹只保存在运行项目的 `eva-memory/`，不要提交到 GitHub。
- 互动语气只作用于 Eva 和用户的对话，不覆盖用户自己的稿件风格。
- 如果用户没有声纹卡，Eva 不默认把稿子写成璐璐腔；如果用户想“以后按我的语气写”，先用 `/eva-user-voice` 生成 `voice-card`。
